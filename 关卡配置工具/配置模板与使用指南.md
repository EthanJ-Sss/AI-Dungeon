# 🎮 关卡配置工具 - 使用指南

**版本**: v1.0  
**更新时间**: 2025-10-23

---

## 📁 工具说明

提供了3种配置关卡的方式，选择最适合你的：

### 1. 🌐 可视化配置器（推荐） - `level_config_editor.html`

**优点**:
- ✅ 可视化界面，操作简单
- ✅ 实时预览配置
- ✅ 自动计算统计数据
- ✅ 一键生成JSON

**使用方法**:
```bash
# 直接用浏览器打开文件
关卡配置工具/level_config_editor.html
```

**操作步骤**:
1. 打开 `level_config_editor.html`
2. 左侧选择要编辑的关卡
3. 填写关卡基础信息
4. 添加敌人并选择怪物类型
5. 点击"生成配置文件"
6. 复制JSON代码
7. 替换到 `astrocade/src/config/levels.json`

---

### 2. 🐍 Python快速配置 - `quick_config.py`

**优点**:
- ✅ 代码化配置，支持版本控制
- ✅ 可以批量生成关卡
- ✅ 支持交互式向导

**使用方法**:

#### A. 生成默认5关配置
```bash
python quick_config.py
# 选择: 1. 生成默认5关配置
```

#### B. 自定义单个关卡
```python
from quick_config import LevelBuilder

# 创建第6关
level6 = (LevelBuilder(6)
    .set_name("冰霜峡谷")
    .set_description("进入冰霜领域...")
    .set_difficulty("中等")
    .set_duration(65)
    .set_burn_damage(10)
    .add_enemy("熔岩巨兽", 1, 0)
    .add_enemy("火焰法师", 0, 1)
    .add_lava_block(2, 5)
    .build()
)

print(json.dumps(level6, indent=2))
```

#### C. 快速配置向导
```bash
python quick_config.py
# 选择: 2. 快速配置向导
# 按提示输入配置
```

---

### 3. 📝 直接编辑JSON - 手动修改

**优点**:
- ✅ 最直接，适合小修改
- ✅ 精确控制每个细节

**使用方法**:
直接编辑 `astrocade/src/config/levels.json`

## 📋 配置模板

### 单个关卡JSON模板

```json
{
  "id": 1,
  "name": "关卡名称",
  "description": "关卡描述文本",
  "difficulty": "新手",
  "scene": "volcano",
  "unlocked": true,
  "duration": 60,
  "burnDamage": 5,
  "lavaBlocks": [
    { "row": 2, "col": 5 }
  ],
  "enemies": [
    {
      "characterId": "monster_training_dummy_attack",
      "position": { "x": 0, "y": 0 }
    }
  ]
}
```

### Python代码模板

```python
from quick_config import LevelBuilder

level = (LevelBuilder(关卡ID)
    .set_name("关卡名称")
    .set_description("关卡描述")
    .set_difficulty("新手")  # 新手/简单/中等/困难/Boss
    .set_duration(60)  # 时长（秒）
    .set_burn_damage(5)  # 环境伤害/秒
    .set_scene("volcano")  # volcano/ice/forest/desert
    .add_enemy("怪物名称", x, y)  # 添加敌人
    .add_lava_block(行, 列)  # 添加熔岩地块
    .build()
)
```

## 🎯 快速修改示例

### 示例1: 修改第1关的环境伤害

**方法A - HTML编辑器**:
1. 打开 `level_config_editor.html`
2. 点击"第1关"
3. 修改"环境燃烧"字段：3 → 5
4. 点击"生成配置文件"
5. 复制JSON

**方法B - Python代码**:
```python
from quick_config import create_level_1

level1 = create_level_1()
level1['burnDamage'] = 5  # 修改环境伤害
```

**方法C - 直接编辑**:
```json
// 找到第1关，修改 burnDamage
"burnDamage": 5  // 从 3 改为 5
```

---

### 示例2: 添加新敌人到第2关

**方法A - HTML编辑器**:
1. 打开 `level_config_editor.html`
2. 选择"第2关"
3. 点击"➕ 添加敌人"
4. 选择怪物类型
5. 设置位置
6. 生成配置

**方法B - Python代码**:
```python
from quick_config import create_level_2

level2 = create_level_2()
level2['enemies'].append({
    "characterId": "monster_fire_mage",
    "position": {"x": 1, "y": 2}
})
```

---

### 示例3: 创建新关卡（第6关）

**Python代码**:
```python
from quick_config import LevelBuilder

level6 = (LevelBuilder(6)
    .set_name("暗影森林")
    .set_description("进入黑暗森林，面对神秘敌人...")
    .set_difficulty("困难")
    .set_duration(75)
    .set_burn_damage(18)
    .set_scene("forest")
    .add_enemy("熔岩巨兽", 1, 1)
    .add_enemy("火焰法师", 0, 1)
    .add_enemy("火焰法师", 2, 1)
    .add_lava_block(1, 5)
    .add_lava_block(3, 5)
    .build()
)

# 保存
import json
with open('level_6.json', 'w', encoding='utf-8') as f:
    json.dump(level6, f, indent=2, ensure_ascii=False)
```

## 🎨 配置字段说明

### 关卡基础属性

| 字段 | 类型 | 说明 | 示例 |
|-----|------|------|------|
| `id` | number | 关卡ID | `1` |
| `name` | string | 关卡名称 | `"火山入口·训练场"` |
| `description` | string | 关卡描述 | `"遭遇训练假人..."` |
| `difficulty` | string | 难度 | `"新手"`, `"简单"`, `"中等"`, `"困难"`, `"Boss"` |
| `scene` | string | 场景 | `"volcano"`, `"ice"`, `"forest"`, `"desert"` |
| `unlocked` | boolean | 是否解锁 | `true` / `false` |
| `duration` | number | 时长（秒） | `60` |
| `burnDamage` | number | 环境伤害/秒 | `5` |

### 敌人配置

```json
{
  "characterId": "monster_xxx",  // 怪物ID
  "position": {
    "x": 0,  // X坐标 (0-2)
    "y": 0   // Y坐标 (0-2)
  }
}
```

**位置说明**:
```
战场布局 (3x3):
(0,0) (1,0) (2,0)  -- 前排
(0,1) (1,1) (2,1)  -- 中排
(0,2) (1,2) (2,2)  -- 后排
```

### 熔岩地块

```json
{
  "row": 2,  // 行 (0-4)
  "col": 5   // 列 (0-7)
}
```

## 💡 配置技巧

### 1. 难度平衡建议

| 关卡 | 建议环境伤害 | 建议时长 | 建议敌人数 |
|-----|------------|---------|-----------|
| 新手 | 3-5 | 50-60秒 | 2-3个 |
| 简单 | 6-10 | 60-70秒 | 3-4个 |
| 中等 | 11-15 | 70-80秒 | 3-5个 |
| 困难 | 16-20 | 70-90秒 | 3-5个 |
| Boss | 15-25 | 70-100秒 | 1-2个 |

### 2. 敌人组合建议

**平衡组合**:
- 1肉盾 + 2输出
- 1坦克 + 1治疗 + 1法师

**突袭组合**:
- 3快速刺客

**防守组合**:
- 2坦克 + 1治疗

**Boss组合**:
- 单个强力Boss
- Boss + 2小怪

### 3. 位置布局技巧

**前排保护型**:
```
[肉盾] [  ] [  ]
[  ] [输出] [  ]
[  ] [  ] [输出]
```

**分散布局**:
```
[刺客] [  ] [  ]
[  ] [坦克] [  ]
[  ] [  ] [刺客]
```

**后排集火型**:
```
[坦克] [  ] [  ]
[法师] [治疗] [法师]
```

## 🔧 常见问题

### Q1: 如何批量修改多个关卡？

**A**: 使用Python脚本：

```python
from quick_config import generate_levels

levels = generate_levels()

# 批量修改环境伤害
for level in levels:
    level['burnDamage'] += 2

# 保存
import json
with open('levels_modified.json', 'w', encoding='utf-8') as f:
    json.dump(levels, f, indent=2, ensure_ascii=False)
```

---

### Q2: 如何添加自定义怪物？

**A**: 
1. 先在 `monsters.json` 中定义怪物
2. 然后在配置工具中使用其ID
3. 或在Python脚本中添加到 `MONSTERS` 字典

---

### Q3: 配置完成后如何应用？

**A**: 
1. 生成JSON配置
2. 复制内容
3. 替换到 `astrocade/src/config/levels.json`
4. 重新构建项目：`npm run build`
5. 部署到服务器

---

### Q4: 如何测试配置？

**A**: 
1. 本地运行：`npm run dev`
2. 进入游戏测试关卡
3. 调整数值
4. 重新生成配置

```
1. 选择配置方式
   ├─ HTML可视化编辑器 (推荐新手)
   ├─ Python脚本 (推荐批量)
   └─ 直接编辑JSON (推荐小修改)
   
2. 配置关卡
   ├─ 基础信息（名称、难度、时长）

3. 生成/保存配置
   ├─ 生成JSON
   └─ 保存到文件
   
4. 应用配置
   ├─ 复制到 levels.json
   ├─ npm run build
   └─ 部署/测试
   
5. 测试验证
   ├─ 本地测试
   ├─ 调整数值
```
