2. **连接服务器**

3. **执行部署脚本**
   ```bash

   chmod +x 部署脚本.sh

   ```

4. **开放防火墙端口**（如果需要）
   ```bash
   sudo ufw allow 8888/tcp
   sudo ufw reload
   ```

5. **访问游戏**
   
   打开浏览器访问：http://43.173.170.5:8888

### 方案2：手动部署步骤

如果自动脚本遇到问题，可以手动执行以下步骤：

#### 1. 上传构建文件
将 `astrocade/dist/` 目录上传到服务器的任意位置（如 `/home/ubuntu/`）

#### 2. 创建部署目录
```bash
sudo mkdir -p /var/www/astrocade
sudo chown -R ubuntu:ubuntu /var/www/astrocade
```

#### 3. 复制文件
```bash
cp -r ~/dist/* /var/www/astrocade/
# 或者根据您上传的实际路径调整
```

#### 4. 创建 Nginx 配置
```bash
sudo nano /etc/nginx/sites-available/astrocade
```

粘贴以下内容：
```nginx
server {
    listen 8888;
    server_name _;
    
    root /var/www/astrocade;
    index index.html;
    
    # 启用 gzip 压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss text/javascript;
    gzip_min_length 1000;
    
    # SPA 路由支持
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
    
    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
}
```

保存文件（Ctrl+X, Y, Enter）

#### 5. 启用站点配置
```bash
sudo ln -s /etc/nginx/sites-available/astrocade /etc/nginx/sites-enabled/
```

#### 6. 测试 Nginx 配置
```bash
sudo nginx -t
```

应该看到 "syntax is ok" 和 "test is successful"

#### 7. 重启 Nginx
```bash
sudo systemctl reload nginx
```

#### 8. 检查服务状态
```bash
sudo systemctl status nginx
sudo netstat -tlnp | grep :8888
```

#### 9. 开放防火墙（如果需要）
```bash
# Ubuntu UFW 防火墙
sudo ufw allow 8888/tcp
sudo ufw reload
sudo ufw status

# 或 firewalld（CentOS/RHEL）
sudo firewall-cmd --permanent --add-port=8888/tcp
sudo firewall-cmd --reload
```

#### 10. 云服务器安全组配置
在云服务器控制台（阿里云/腾讯云/AWS等）的安全组设置中：
- 添加入站规则
- 协议：TCP
- 端口：8888
- 源：0.0.0.0/0（允许所有访问）

## 故障排查

### 问题1：无法访问网站

**检查防火墙**：
```bash
sudo ufw status
sudo ufw allow 8888/tcp
```

**检查云服务器安全组**：
登录云服务器控制台，确保安全组开放了 8888 端口

**检查 Nginx 是否运行**：
```bash
sudo systemctl status nginx
sudo systemctl restart nginx
```

### 问题2：502 Bad Gateway 或其他错误

**查看 Nginx 错误日志**：
```bash
sudo tail -f /var/log/nginx/error.log
```

**检查文件权限**：
```bash
sudo chown -R www-data:www-data /var/www/astrocade
sudo chmod -R 755 /var/www/astrocade
```

### 问题3：端口已被占用

**检查端口占用**：
```bash
sudo netstat -tlnp | grep :8888
```

如果 8888 端口已被占用，修改配置文件中的端口号

### 问题4：页面显示空白或 404

**检查文件路径**：
```bash
ls -la /var/www/astrocade/index.html
```

确保 index.html 文件存在

**检查 Nginx 配置中的 root 路径**：
```bash
sudo nano /etc/nginx/sites-available/astrocade
# 确认 root 路径正确
```

## 更新部署

如果需要更新游戏：

1. 本地重新构建
   ```bash
   cd astrocade
   npm run build
   ```

2. 上传新的 dist 文件夹到服务器

3. 替换文件
   ```bash
   rm -rf /var/www/astrocade/*
   cp -r ~/新的dist路径/* /var/www/astrocade/
   ```

4. 清除浏览器缓存后访问

## 卸载/停止服务

停止服务：
```bash
sudo rm /etc/nginx/sites-enabled/astrocade
sudo systemctl reload nginx
```

完全删除：
```bash
sudo rm /etc/nginx/sites-available/astrocade
sudo rm /etc/nginx/sites-enabled/astrocade
sudo rm -rf /var/www/astrocade
sudo systemctl reload nginx
```
