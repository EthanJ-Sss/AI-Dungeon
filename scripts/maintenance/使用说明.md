## 🚀 快速使用

### 方法1：双击运行 ⭐ 推荐

**在项目根目录**:

**或在 scripts/maintenance/ 目录**:
```
双击运行：整理项目目录.bat
```


## 📁 整理内容

```

目标位置: docs\completed\
```

- ✅关卡难度设计v3.0完成.md
- ✅Bug修复-敌人消失问题.md
- ✅Sprint1完成.md

---

#### 2. 测试文档 (🎯)

## ✅ 执行流程

脚本执行时会依次进行以下步骤：

```
1. 检查是否在项目根目录

3. 整理已完成功能文档 (✅)
4. 整理测试文档 (🎯)

6. 整理庆祝文档 (🎉🎊)

8. 整理修复工具 (🔧)
9. 整理指引文档 (👉)
10. 整理数据分析 (📊)
11. 整理特定设计文档
12. 整理开发文档
13. 整理部署脚本
14. 整理开发脚本
15. 整理维护脚本
```

## 📊 执行结果

脚本运行完成后会显示：

```
===============================================
              整理完成！
===============================================
移动文件数: 45
跳过文件数: 12

项目目录已整理完毕！
请查看: 📋项目目录管理规范.md 了解目录结构
```

**说明**:
- **移动文件数**: 成功移动到目标目录的文件数量
- **跳过文件数**: 目标位置已存在，跳过的文件数量

---

## 🔍 跳过规则

以下情况文件会被跳过：

1. **目标位置已存在同名文件**
   ```
   [跳过] ✅关卡难度设计v3.0完成.md (已存在)
   ```

2. **文件不在根目录**
   - 脚本只整理根目录的文件
   - 已在正确位置的文件不会移动

3. **文件不匹配任何规则**
   - 不带Emoji标识的文件
   - 不在特定文件列表中的文件

## ⚠️ 注意事项

### 运行前检查

✅ **确认在项目根目录运行**:
```
当前目录应包含：
- astrocade/ 文件夹
- docs/ 文件夹
- scripts/ 文件夹
```

✅ **备份重要文件**（可选）:
- 首次运行建议先备份
- 或使用Git版本控制

### 安全措施

- ✅ 脚本不会删除任何文件
- ✅ 只会移动文件，不会修改内容
- ✅ 如果目标位置已存在，会跳过
- ✅ 可以多次运行，不会重复移动

## 🐛 常见问题

### Q1: 提示"找不到文件"怎么办？

**A**: 检查是否在项目根目录运行脚本。

**解决方法**:
```batch
cd e:\circletest
.\scripts\maintenance\整理项目目录.bat
```

---

### Q2: 文件没有被移动？

**A**: 可能的原因：
1. 文件不在根目录
2. 文件名不匹配规则
3. 目标位置已存在同名文件

**检查方法**:
```
查看脚本输出，会显示：
[移动] 文件名 → 目标目录
或
[跳过] 文件名 (已存在)
```

---

### Q3: 统计数字不准确？

**A**: 这是已知问题，批处理版本可能统计不准确。

**解决方法**: 使用PowerShell版本
```powershell
.\scripts\maintenance\整理项目目录.ps1
```

---

### Q4: 想撤销移动操作？

**A**: 手动移回或使用Git还原

**方法1 - 手动移回**:
```
从目标目录复制文件回根目录
```

**方法2 - Git还原**:
```bash
git checkout -- .
```

---

### Q5: 如何添加新的整理规则？

**A**: 编辑脚本文件，添加新的 `call :MoveFile` 行

**示例**:
```batch
echo [第XX步] 整理XXX文档...
call :MoveFile "新文件名.md" "docs\design"
```
