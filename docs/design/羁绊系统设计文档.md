## 🎯 设计理念

### 1. 核心目标

**为什么需要羁绊系统？**
- ✅ **增加阵容搭配深度** - 不只看单个角色强度，更看团队协同
- ✅ **提升策略性** - 玩家需要思考角色组合
- ✅ **增加角色价值** - 普通角色也能通过羁绊发挥作用
- ✅ **延长游戏寿命** - 探索不同羁绊组合的乐趣
- ✅ **故事性增强** - 通过羁绊展现角色背景关系

### 2. 设计原则

**KISS原则 (Keep It Simple, Stupid)**
- 🎯 **易懂** - 羁绊效果一目了然
- 🎯 **直观** - 自动激活，无需手动操作
- 🎯 **平衡** - buff不过强，不破坏平衡
- 🎯 **有趣** - 鼓励尝试不同组合

### 2. 激活机制

```typescript
// 羁绊激活条件
interface BondActivation {
  bondId: string;
  requiredCount: number;      // 需要的角色数量
  requiredTags: string[];     // 需要的标签
  exclusive?: boolean;        // 是否互斥（不能同时激活其他羁绊）
}

// 激活逻辑
function checkBondActivation(team: Character[]): ActivatedBond[] {
  const activatedBonds: ActivatedBond[] = [];
  
  for (const bond of allBonds) {
    const matchCount = team.filter(char => 
      bond.requiredTags.some(tag => char.bondTags.includes(tag))
    ).length;
    
    if (matchCount >= bond.requiredCount) {
      activatedBonds.push({
        bond,
        level: calculateBondLevel(matchCount, bond),
        characters: getMatchingCharacters(team, bond)
      });
    }
  }
  
  return activatedBonds;
}
```

### 1. 羁绊检测系统

```typescript
class BondSystem {
  private bonds: Bond[];
  private activatedBonds: ActivatedBond[] = [];
  
  /**
   * 检测并激活羁绊
   */
  public checkAndActivateBonds(team: Character[]): ActivatedBond[] {
    this.activatedBonds = [];
    
    // 1. 检查所有羁绊
    for (const bond of this.bonds) {
      const activation = this.checkBondActivation(bond, team);
      
      if (activation) {
        this.activatedBonds.push(activation);
      }
    }
    
    // 2. 按优先级排序
    this.activatedBonds.sort((a, b) => 
      b.bond.ui.priority - a.bond.ui.priority
    );
    
    // 3. 应用羁绊效果
    this.applyBondEffects(team);
    
    return this.activatedBonds;
  }
  
  /**
   * 检查单个羁绊是否激活
   */
  private checkBondActivation(
    bond: Bond, 
    team: Character[]
  ): ActivatedBond | null {
    // 故事羁绊：检查指定角色
    if (bond.activation.exactCharacters) {
      const hasAll = bond.activation.exactCharacters.every(charId =>
        team.some(char => char.id === charId)
      );
      
      if (!hasAll) return null;
      
      const triggeredChars = team.filter(char =>
        bond.activation.exactCharacters!.includes(char.id)
      );
      
      return this.createActivatedBond(bond, triggeredChars, 1);
    }
    
    // 标签羁绊：统计匹配数量
    const matchedChars = team.filter(char =>
      bond.activation.requiredTags.some(tag => 
        char.bondTags.includes(tag)
      )
    );
    
    if (matchedChars.length < bond.activation.minCount) {
      return null;
    }
    
    // 确定激活等级
    const level = this.calculateBondLevel(
      bond, 
      matchedChars.length
    );
    
    return this.createActivatedBond(bond, matchedChars, level);
  }
  
  /**
   * 计算羁绊等级
   */
  private calculateBondLevel(bond: Bond, count: number): number {
    let level = 0;
    
    for (const bondLevel of bond.levels) {
      if (count >= bondLevel.requiredCount) {
        level = bondLevel.level;
      }
    }
    
    return level;
  }
  
  /**
   * 创建激活的羁绊对象
   */
  private createActivatedBond(
    bond: Bond,
    characters: Character[],
    level: number
  ): ActivatedBond {
    const bondLevel = bond.levels.find(l => l.level === level)!;
    
    return {
      bond,
      level,
      triggeredCharacters: characters,
      effects: bondLevel.effects.map(effect => ({
        effect,
        targets: this.getEffectTargets(effect, characters),
        value: effect.value
      }))
    };
  }
  
  /**
   * 获取效果目标
   */
  private getEffectTargets(
    effect: BondEffect,
    triggeredChars: Character[]
  ): Character[] {
    switch (effect.target) {
      case 'all':
        return this.currentTeam;
      case 'tagged':
        return triggeredChars;
      case 'specific':
        // 根据条件筛选
        return this.filterByCondition(effect.condition);
      default:
        return [];
    }
  }
  
  /**
   * 应用羁绊效果到角色
   */
  private applyBondEffects(team: Character[]): void {
    // 重置所有羁绊buff
    team.forEach(char => {
      char.bondBuffs = [];
    });
    
    // 应用激活的羁绊
    for (const activated of this.activatedBonds) {
      for (const appliedEffect of activated.effects) {
        for (const target of appliedEffect.targets) {
          this.applyEffectToCharacter(
            target,
            appliedEffect.effect,
            appliedEffect.value,
            activated.bond
          );
        }
      }
    }
  }
  
  /**
   * 应用效果到单个角色
   */
  private applyEffectToCharacter(
    character: Character,
    effect: BondEffect,
    value: number,
    bond: Bond
  ): void {
    const buff: BondBuff = {
      bondId: bond.id,
      bondName: bond.name,
      effectType: effect.type,
      value: value,
      description: effect.description
    };
    
    character.bondBuffs.push(buff);
    
    // 根据效果类型修改角色属性
    switch (effect.type) {
      case EffectType.HP_PERCENT:
        character.currentMaxHP *= (1 + value / 100);
        break;
      case EffectType.ATTACK_PERCENT:
        character.currentAttack *= (1 + value / 100);
        break;
      case EffectType.CRIT_RATE:
        character.critRate += value;
        break;
      // ...其他效果类型
    }
  }
  
  /**
   * 获取角色的羁绊buff说明
   */
  public getCharacterBondBuffs(character: Character): string[] {
    return character.bondBuffs.map(buff =>
      `[${buff.bondName}] ${buff.description}`
    );
  }
}

interface BondBuff {
  bondId: string;
  bondName: string;
  effectType: EffectType;
  value: number;
  description: string;
}
```

## 📊 平衡性设计

### 1. Buff数值设计原则

**基础羁绊 (2人激活):**
- 数值加成：15-20%
- 效果：单一、实用
- 目标：提供明显但不过分的优势

**进阶羁绊 (3人激活):**
- 数值加成：30-45%
- 效果：多重、强力
- 目标：奖励深度阵容搭配

**特殊羁绊 (4人特定组合):**
- 数值加成：45%+
- 效果：独特机制
- 适用范围：稀有度羁绊和自由佣兵（4个不同阵营）

**传说羁绊 (故事组合):**
- 数值加成：25-40%
- 效果：独特联动机制
- 目标：提供趣味性和角色关系展现

### 2. 羁绊冲突设计

**互补型羁绊：** 可以同时激活，效果叠加
```
例如：火焰同盟 + 奥术共鸣
→ 火法师同时享受两个羁绊
```

**竞争型羁绊：** 满足条件时选择更高优先级
```
例如：精英小队 vs 稀有战队
→ 如果2精英+3稀有，优先显示精英小队
```

**互斥型羁绊：** 不能同时激活（极少使用）
```
例如：光明阵营 vs 黑暗阵营（如果未来添加）
```

### 3. 平衡性测试矩阵

| 组合类型 | 总Buff强度 | 通关能力 | 趣味性 | 平衡评分 |
|----------|-----------|---------|--------|---------|
| 纯元素队 | ★★★★★ | ★★★★☆ | ★★★☆☆ | 良好 |
| 纯职业队 | ★★★★☆ | ★★★☆☆ | ★★★☆☆ | 良好 |
| 稀有度队 | ★★★☆☆ | ★★☆☆☆ | ★★☆☆☆ | 需调整 |
