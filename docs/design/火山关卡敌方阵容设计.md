# 火山关卡敌方阵容设计

**更新日期**: 2025-10-22  
**版本**: 全新小怪系统  
**设计理念**: 专属小怪，独立技能，不与英雄系统共用

---

## 设计原则

### 核心理念
1. **独立系统**: 小怪与英雄完全分离，拥有独特的技能和属性
2. **主题一致性**: 火山环境为主题，以火系和土系小怪为主
3. **难度递进**: 从简单的爬行者到强大的Boss，逐步提升挑战
4. **环境互动**: 熔岩喷发位置与敌人配置相辅相成
5. **战术多样**: 每关敌人组合不同，需要不同的战术应对

### 元素分布
- **火系小怪**: 免疫环境燃烧，攻击具有点燃效果
- **土系小怪**: 高生命值，强防御，控制能力
- **Boss**: 多技能组合，机制复杂

## 平衡性考量

### 数值设计
- **关卡1**: 总HP 840，总DPS ~78
- **关卡2**: 总HP 1040，总DPS ~94，增加坦克和远程
- **关卡3**: 总HP 910，总DPS ~123，提高单体质量
- **关卡4**: 总HP 1070，总DPS ~82，但防御极高
- **关卡5**: 总HP 1200，DPS ~55，但技能爆发强

### 克制推荐
- **关卡1-2**: 任何合理队伍都能通过
- **关卡3**: 需要应对刺客突袭，建议带控制
- **关卡4**: 建议水系/冰系克制火系，优先杀法师
- **关卡5**: 需要高生存队伍，建议带治疗+坦克
