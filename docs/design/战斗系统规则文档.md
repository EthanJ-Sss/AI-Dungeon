## 🎮 战场布局

### 棋盘结构
- **尺寸**：7行 × 9列
- **网格大小**：每格70×70像素
- **布局方向**：左右对战（非上下）

### 阵营区域

#### 我方区域（蓝色）
- **位置**：列2-4，行3-5
- **大小**：3×3格子
- **视觉标识**：
  - 蓝色半透明背景（透明度10%）
  - 蓝色加粗边框（3px）
  - 顶部标签："我方区域"

#### 敌方区域（红色）
- **位置**：列6-8，行3-5
- **大小**：3×3格子
- **视觉标识**：
  - 红色半透明背景（透明度10%）
  - 红色加粗边框（3px）
  - 顶部标签："敌方区域"

### 战场示意图

## ⚔️ 战斗流程

### 1. 战前准备
1. **阵型布置阶段**
   - 玩家在阵型界面拖拽角色到3×3格子
   - 可以看到敌方的阵型和角色
   - 确认后进入战斗场景

2. **角色生成**
   - 根据阵型配置，在对应格子生成角色
   - 本地坐标(0-2, 0-2)自动转换为全局棋盘坐标
   - 我方：全局坐标 = (列2, 行3) + 本地坐标
   - 敌方：全局坐标 = (列6, 行3) + 本地坐标

### 2. 战斗执行
1. **计时器启动**
   - 战斗时长：30秒
   - 每秒更新一次显示
   - 剩余10秒时变为红色警告

2. **AI循环（每100ms）**
   - 遍历所有存活角色
   - 执行AI行为决策
   - 更新角色状态

### 3. 战斗结束
- **胜利条件**：消灭所有敌人
- **失败条件**：
  - 己方全灭
  - 30秒超时

## 🤖 角色行为规则

### AI决策流程
```
每100ms执行一次：
1. 检查战斗是否已结束 → 是：停止AI
2. 检查角色是否存活 → 否：跳过
3. 检查容器是否有效 → 否：跳过
4. 筛选存活的敌方目标
5. 如果没有目标 → 触发战斗结束检查
6. 寻找最近的敌人
7. 计算距离
8. 判断：在攻击范围内？
   - 是 → 尝试攻击
   - 否 → 向目标移动
```

### 移动规则
- **寻路**：直线接近最近敌人
- **移动速度**：角色移速 × 5倍加速
- **计算公式**：
  ```typescript
  角度 = 从自己到目标的角度
  有效速度 = 移速 × 5
  新位置X = 当前X + cos(角度) × 有效速度 × 0.1
  新位置Y = 当前Y + sin(角度) × 有效速度 × 0.1
  ```

### 攻击规则

#### 攻击范围
- **近战（Melee）**：80像素
- **远程（Ranged）**：200像素

#### 攻击冷却
- **近战**：1000ms（1秒）
- **远程**：1500ms（1.5秒）

#### 攻击流程
1. **检查冷却时间**
   - 未冷却完成 → 不能攻击
   - 已冷却完成 → 继续

2. **执行攻击动画**
   - 攻击者放大1.2倍（100ms）
   - Yoyo效果（放大后缩回）

3. **伤害计算**
   - 近战：直接造成伤害
   - 远程：发射子弹，命中后造成伤害

4. **记录攻击时间**
   - 更新lastAttackTime
   - 开始下一轮冷却

### 远程攻击特殊机制
- **子弹视觉**：黄色圆形（半径5px）
- **飞行速度**：500ms到达目标
- **飞行效果**：直线移动
- **命中判定**：到达目标位置时触发伤害

## 💔 伤害与死亡

### 伤害计算
```typescript
当前HP = max(0, 当前HP - 攻击伤害)
HP百分比 = 当前HP / 最大HP
```

### 视觉反馈

#### 1. 血条更新
- **宽度**：50px × HP百分比
- **颜色变化**：
  - \> 50%：绿色 (0x00ff00)
  - 20%-50%：橙色 (0xffaa00)
  - < 20%：红色 (0xff0000)

#### 2. 受击效果
- **闪烁动画**：透明度降至50%
- **持续时间**：100ms
- **重复**：1次（yoyo效果）

#### 3. 伤害数字
- **显示**：红色"-伤害值"
- **位置**：角色上方30px
- **动画**：向上漂浮30px同时淡出
- **持续**：1000ms后销毁

### 死亡处理

#### 当HP ≤ 0时：
1. **标记死亡**
   ```typescript
   unit.isAlive = false
   ```

2. **从容器映射中移除**
   ```typescript
   this.allUnits.delete(unit.character.id)
   ```

3. **死亡动画**（500ms）
   - 透明度降至0
   - 缩放至0（scaleX, scaleY）
   
4. **销毁容器**
   ```typescript
   container.destroy()
   ```

5. **触发战斗结束检查**
   ```typescript
   this.checkBattleEnd()
   ```

## 🏆 战斗胜负判定

### 检查时机
1. 角色死亡时
2. AI发现没有可攻击目标时
3. 倒计时结束时

### 判定逻辑
```typescript
checkBattleEnd() {
  if (战斗已结束) return;
  
  存活敌人数 = 敌方单位.filter(u => u.isAlive).length;
  存活友军数 = 我方单位.filter(u => u.isAlive).length;
  
  if (存活敌人数 === 0) {
    结束战斗('win');
  } else if (存活友军数 === 0) {
    结束战斗('lose');
  }
}
```

### 超时判定
```typescript
if (战斗时间 <= 0) {
  结束战斗('lose');
}
```

### 结束流程
1. **设置结束标志**
   ```typescript
   this.battleEnded = true
   ```

2. **停止所有定时器**
   ```typescript
   this.time.removeAllEvents()
   ```

3. **显示结果UI**
   - 黑色半透明遮罩
   - 胜利/失败文字（绿色/红色）
   - "返回主页"按钮

4. **保存结果**
   ```typescript
   gameStore.setBattleResult(result)
   ```

5. **触发事件**
   ```typescript
   game.events.emit('battle-end', result)
   ```

## 🔧 技术实现细节

### 状态管理

#### 防止重复执行
```typescript
// 在所有关键方法中检查
if (this.battleEnded) return;
```

#### 容器有效性检查
```typescript
// 检查容器是否存在且激活
if (!container || !container.active) return;
```

#### 角色存活性检查
```typescript
// 多重验证
if (!unit.isAlive) return;
const aliveTargets = targets.filter(t => t.isAlive);
```

### 内存管理

#### 战斗开始时（create方法）
```typescript
// 清理所有状态
this.battleEnded = false;
this.battleTimer = 30;
this.playerUnits = [];
this.enemyUnits = [];
this.allUnits.clear();
```

#### 角色死亡时
```typescript
// 从Map中移除引用
this.allUnits.delete(character.id);
// 销毁Phaser容器
container.destroy();
```

#### 战斗结束时
```typescript
// 停止所有定时器
this.time.removeAllEvents();
// 设置结束标志，阻止后续更新
this.battleEnded = true;
```

### 坐标系统

#### 三层坐标系
1. **本地网格坐标**：阵型界面使用(0-2, 0-2)
2. **全局棋盘坐标**：战场上的格子坐标(0-8, 0-6)
3. **像素坐标**：Phaser场景中的实际位置

#### 转换公式
```typescript
// 本地 → 全局
全局列 = 区域起始列 + 本地X
全局行 = 区域起始行 + 本地Y

// 全局 → 像素
像素X = 棋盘偏移X + 全局列 × 格子大小 + 格子大小/2
像素Y = 棋盘偏移Y + 全局行 × 格子大小 + 格子大小/2
```

### 性能优化

#### AI更新频率
- **频率**：每100ms（10Hz）
- **原因**：平衡响应性和性能

#### 移动速度优化
- **基础移速**：角色属性中的moveSpeed
- **加速倍率**：5倍
- **微调系数**：0.1
- **最终速度**：`moveSpeed × 5 × 0.1`

#### 条件短路
```typescript
// 使用多个return提前退出
if (!unit.isAlive) return;
if (!container) return;
// 避免不必要的计算
```

## 🐛 已修复的Bug

### Bug #1：角色位置错误
**问题**：角色生成在错误的位置
**原因**：行列坐标理解错误，实现成了上下结构
**修复**：
- 我方区域：列2-4，行3-5（左侧）
- 敌方区域：列6-8，行3-5（右侧）

### Bug #2：角色死亡后战斗卡住
**问题**：第一个角色死后，战斗停止响应
**原因**：
1. 死亡角色容器被销毁但未从`allUnits`移除
2. AI循环中获取到null容器导致错误
3. 缺少`battleEnded`标志，重复触发结束逻辑

**修复**：
1. 死亡时从`allUnits.delete()`移除
2. 所有获取容器处添加有效性检查
3. 添加`battleEnded`标志防止重复执行
4. 场景重置时清空所有状态

### Bug #3：重复执行战斗结束
**问题**：战斗结束逻辑被多次调用
**原因**：多个角色同时死亡时，每个都触发`checkBattleEnd`
**修复**：在`endBattle`和`checkBattleEnd`开始处检查`battleEnded`标志
