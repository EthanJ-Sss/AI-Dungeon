# 英雄系统重构说明

**日期**: 2025-10-22  
**版本**: v3.0 - 元素被动系统

---

## 🎯 重构核心理念

### 设计哲学
- **元素即被动**: 被动技能完全由元素决定
- **简化配置**: 减少重复，提高可维护性
- **清晰分层**: 属性→元素→被动→主动
- **易于扩展**: 新增英雄只需配置基础属性和选择技能

---

## 📊 重构对比

### 旧系统
```json
{
  "name": "炎魔萨尔",
  "element": "fire",
  "passiveSkills": ["burn_immune", "low_hp_damage_boost"],
  "skills": ["skill_fire_nova", "skill_molten_armor"]
}
```

**问题**:
- ❌ 每个英雄都要配置被动技能
- ❌ 相同元素英雄被动重复
- ❌ 配置繁琐，容易出错
- ❌ 修改被动需要更新所有英雄

### 新系统
```json
{
  "name": "炎魔萨尔",
  "element": "fire",
  "passiveSkills": [],
  "skills": ["skill_molten_armor"]
}
```

**优势**:
- ✅ 被动技能由element自动关联
- ✅ 相同元素英雄共享被动
- ✅ 配置简洁，减少错误
- ✅ 修改被动只需更新元素定义

---

## 🔥 5种元素被动技能

### 设计规则
1. **每个元素1个被动技能**
2. **所有同元素英雄共享**
3. **被动技能体现元素核心特性**
4. **与火山主题紧密结合**

### 具体定义

#### 🔥 火元素：【炽热之躯】
```javascript
element: "fire"
passive: {
  burnImmune: true,  // 完全免疫燃烧伤害
  igniteChance: 0.3, // 30%几率点燃敌人
  igniteDuration: 3, // 点燃持续3秒
  igniteDamage: 0.4  // 造成伤害总和的40%
}
```

**适用英雄**: 炎魔萨尔、凤凰女、烈焰刺客、火焰射手

#### 💧 水元素：【流水之势】
```javascript
element: "water"
passive: {
  fireBonus: 1.4,    // 对火系140%伤害
  hpRegen: 0.02,     // 每5秒回复2%HP
  regenInterval: 5   // 回复间隔5秒
}
```

**适用英雄**: 海神波塞冬、潮汐使者、深渊刺客

#### ❄️ 冰元素：【寒冰护体】
```javascript
element: "ice"
passive: {
  burnReduction: 0.7,   // 燃烧伤害降低70%
  fireBonus: 1.2,       // 对火系120%伤害
  slowChance: 0.35,     // 35%几率减速
  slowAmount: 0.35,     // 减速35%
  slowDuration: 2       // 持续2秒
}
```

**适用英雄**: 艾莎、洛基、极地游侠、冰霜刺客

#### 🪨 土元素：【大地之佑】
```javascript
element: "earth"
passive: {
  hpBonus: 1.3,         // +30%最大HP
  startShield: 0.2,     // 开战20%HP护盾
  shieldRegen: 0.1,     // 护盾再生10%HP
  regenCooldown: 10     // 再生冷却10秒
}
```

**适用英雄**: 泰坦石像、沙漠守护者、大地萨满、岩石射手

#### ⚪ 无元素：无被动
```javascript
element: "neutral"
passive: null
```

**适用英雄**: 战术大师、全能战士、神秘刺客

```json

```
**说明**: 被动由element自动关联，无需配置

```typescript
class ElementManager {
  // 元素被动技能映射
  private elementPassives = {
    fire: {
      name: '炽热之躯',
      effects: {
        burnImmune: true,
        igniteChance: 0.3,
        igniteDuration: 3,
        igniteDamage: 0.4
      }
    },
    water: {
      name: '流水之势',
      effects: {
        fireBonus: 1.4,
        hpRegen: 0.02,
        regenInterval: 5
      }
    },
    // ... 其他元素
  };

  // 获取角色被动技能
  getPassiveSkill(element: string) {
    return this.elementPassives[element] || null;
  }

    }
  }
}
```

### Character配置验证
```typescript
function validateCharacter(char: Character) {
  // 验证：有元素角色的技能必须匹配元素
  if (char.element && char.element !== 'neutral') {
    const skill = getSkill(char.skills[0]);
    if (skill.element !== char.element) {
      throw new Error(
        `角色${char.name}的元素是${char.element}，但技能${skill.name}的元素是${skill.element}`
      );
    }
  }
  
  // 验证：被动技能数组必须为空
  if (char.passiveSkills && char.passiveSkills.length > 0) {
    console.warn(
      `角色${char.name}的passiveSkills应该为空，被动由元素决定`
    );
  }
}
```

## 📈 优势总结

### 1. 配置简化
- **减少90%的被动配置**
- 18个英雄 × 1-3个被动 = 36-54项配置 → **0项**
- 被动配置集中在5个元素定义中

### 2. 维护性提升
- **修改元素被动**：只需修改1处（元素定义）
- **新增英雄**：只需配置基础属性和选择技能
- **调整平衡**：元素级别调整，影响所有同元素英雄

### 3. 一致性保证
- **同元素英雄体验一致**
- **减少配置错误**
- **元素特性更突出**

### 4. 扩展性增强
- **新增英雄**：复制配置模板，改属性，选技能
- **新增元素**：定义元素被动 + 技能池
- **新增技能**：添加到对应技能池
