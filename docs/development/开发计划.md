# AstroCade 游戏开发计划

## 项目概述

**项目名称：** AstroCade  
**项目类型：** Roguelike + 角色养成游戏  
**开发方法：** 敏捷开发（4个Sprint迭代）  
**核心玩法：** 招募英雄 → 组队挑战 → 养成提升 → 击败最终Boss

---

## 开发目标

制作一个只包含"核心循环"的可体验版本，快速上线测试验证：
- ✅ 玩家通过招募获得角色
- ✅ 组成3人小队挑战关卡
- ✅ 战胜敌人获得俘虏学习技能
- ✅ 通过数值提升或角色搭配通关

### 3. 基础战斗系统

#### 战场设计
- **双方各3×3网格战场**（共18格）
- 玩家方：左侧3×3网格
- 敌人方：右侧3×3网格
- 中间留有空隙作为战场中央区域
- 战斗前需要玩家拖拽角色到己方3×3格子内布阵
- 布阵时可以看到敌方的角色和阵型

#### 职业AI逻辑

**战士/弓手AI：**
```
1. 扫描战场，找到最近的敌人
2. 如果距离 > 攻击范围，向敌人移动
3. 如果距离 <= 攻击范围，停止移动并攻击
4. 重复步骤1
```

**刺客AI：**
```
1. 战斗开始，瞬移到敌方后排
2. 扫描战场，找到最近的敌人
3. 如果距离 > 攻击范围，向敌人移动
4. 如果距离 <= 攻击范围，停止移动并攻击
5. 重复步骤2
```

#### 攻击系统
- **近战攻击：**
  - 攻击范围：1格
  - 攻击动画：挥砍动作
  - 攻击间隔：1秒
  
- **远程攻击：**
  - 攻击范围：5格
  - 攻击动画：射箭/发射子弹
  - 攻击间隔：1.5秒

#### 胜负判定
- 敌方全部死亡 → 玩家胜利
- 玩家全部死亡 → 玩家失败
- 30秒超时 → 玩家失败

#### 阵型布置系统
- 进入战斗前先进入布阵界面
- 显示己方3×3网格和敌方3×3网格
- 玩家可以拖拽自己的角色到己方格子内
- 可以看到敌方角色的位置和类型
- 最多放置3个角色
- 确认布阵后开始战斗

#### 技能配置表：SkillConfig_v1.csv
| id | name | type | cd | range | damage | effect |
|----|------|------|----|----|----|----|
| 1 | 火球术 | active | 10 | 5 | 50 | 单体伤害 |
| 2 | 紧急回血 | active | 15 | 0 | 0 | 回复20%HP |
| 3 | 快速闪现 | active | 12 | 0 | 0 | 向前瞬移3米 |
| 4 | 减速射击 | active | 8 | 5 | 20 | 减速30%持续2秒 |
| 5 | 嘲讽吸引 | active | 20 | 2 | 0 | 强制攻击自己1秒 |

#### 技能CD机制
- 对局开始，所有技能进入CD
- 普攻1次 → CD -1秒
- 受击1次 → CD -0.5秒
- CD转好后立即释放
- 多技能同时转好 → 按技能栏顺序释放

## 风险与应对

| 风险 | 等级 | 应对措施 |
|------|------|---------|
| AI战斗不够智能 | 中 | 先实现简单AI，逐步优化 |
| 技能系统复杂度高 | 高 | 分阶段实现，先主动后被动 |
| 数值平衡难度大 | 中 | 提前设计配置表，预留调整空间 |
| 性能问题 | 低 | 控制战场单位数量，优化渲染 |
| 开发时间超期 | 中 | 严格控制范围，可删减非核心功能 |
