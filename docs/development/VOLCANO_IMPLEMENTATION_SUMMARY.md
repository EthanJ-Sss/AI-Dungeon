## 技术实现亮点

### 1. 元素系统设计

```typescript
// 元素克制关系
冰系 → 火系 (+30%伤害)
火系 → 冰系 (-20%伤害)
火系 → 燃烧 (免疫100%)
冰系 → 燃烧 (抗性50%)
大地系 → 岩浆 (抗性40%)
```

### 2. 环境机制

**燃烧系统：**
- 每秒触发一次
- 全场角色受影响
- 根据元素属性计算最终伤害
- 视觉特效：🔥火焰粒子向上飘动

**岩浆喷发系统：**
- 5个固定地块（玩家侧2个，敌方侧2个，中央1个）
- 错峰触发（避免同时喷发）
- 警告机制：1.5秒红色闪烁
- 喷发特效：💥爆炸动画
- 10秒周期，50点伤害

### 3. 技能系统扩展

**火系技能：**
- 火球爆裂：主目标+AOE二段伤害
- 烈焰冲击：冲刺攻击+火焰尾迹

**冰系技能：**
- 寒冰箭：伤害+减速+元素克制
- 冰霜护盾：护盾吸收伤害
- 冰封打击：高伤害+冻结控制

**治疗技能：**
- 圣光庇护：治疗+驱散燃烧
- 生命之泉：范围持续治疗

**Boss技能：**
- 炎魔之怒：大范围AOE爆发
- 熔岩召唤：战场环境控制

## 游戏平衡性设计

### 关卡难度曲线

| 关卡 | 燃烧伤害 | 时长 | 敌人配置 | 难度 |
|------|----------|------|----------|------|
| 1 - 火山入口 | 3/秒 | 30秒 | 3个新兵 | 简单 |
| 2 - 熔岩小径 | 5/秒 | 35秒 | 3个战士 | 中等 |
| 3 - 火山通道 | 8/秒 | 40秒 | 3个精英 | 中等 |
| 4 - 熔岩核心 | 12/秒 | 45秒 | 3个强敌 | 困难 |
| 5 - 炎魔之王 | 15/秒 | 60秒 | Boss单位 | Boss |

### 元素配队策略

**推荐配置：**
1. **火系核心**：免疫燃烧，适合长期战斗
2. **冰系输出**：克制火系敌人，+30%伤害
3. **大地坦克**：岩浆抗性，保护后排
4. **治疗支援**：驱散燃烧，持续回血

**反面教材：**
- ❌ 全中立角色：燃烧全额伤害
- ❌ 无治疗配置：难以支撑60秒Boss战
- ❌ 站在岩浆地块：额外受到50伤害
