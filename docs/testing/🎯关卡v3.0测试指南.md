## 🐛 常见问题

### Q1: 治疗技能不生效？
**检查**：
1. 控制台是否有错误日志
2. 火焰祭司的技能CD（8秒）
3. 是否有受伤的队友

### Q2: 冲锋技能不生效？
**检查**：
1. 控制台是否有错误日志
2. 冲锋者的技能CD（6秒）
3. 是否有可攻击的目标

### Q3: 怪物不攻击？
**检查**：
1. 是否正确布置了玩家角色
2. 关卡是否正常加载
3. 控制台错误日志
