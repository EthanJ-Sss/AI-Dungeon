## 📝 测试清单

### ✅ 关卡1：火山入口（新手教学）

**预期体验**: 极度简单，轻松获胜

**测试要点**:
- [ ] 只有1个弱小敌人（幼年爬行者，180HP）
- [ ] 没有熔岩喷发障碍
- [ ] 环境燃烧很低（3点/秒）
- [ ] 任何单个角色都能轻松获胜
- [ ] 通关后能学习1次技能
- [ ] 时间50秒非常充足

**测试方法**: 
- 用1个最弱的角色测试，应该也能轻松获胜
- 站着不动，环境伤害也不会致命（50秒=150伤害）

---

### ✅ 关卡2：熔岩小径（简单）

**预期体验**: 适合新手，学习集火

**测试要点**:
- [ ] 3个敌人：2个近战爬行者 + 1个远程投石手
- [ ] 总HP 820，中等难度
- [ ] 1个熔岩点，不影响主战场
- [ ] 环境燃烧8点/秒
- [ ] 推荐2-3个角色组队

**测试方法**:
- 测试不同集火顺序（先杀远程 vs 先杀近战）
- 观察投石手的远程威胁

---

### ✅ 关卡3：火山通道（中等）

**预期体验**: 有一定挑战，需要战术

**测试要点**:
- [ ] 4个敌人：1坦克 + 3输出
- [ ] 熔岩巨兽会开盾（120护盾）
- [ ] 熔岩巨兽会跳跃眩晕
- [ ] 火焰哨兵会点燃持续伤害
- [ ] 2个熔岩点，有一定威胁
- [ ] 需要合理的集火顺序

**测试方法**:
- 测试巨兽护盾机制是否生效
- 测试跳跃眩晕是否正常
- 测试点燃DoT效果

---

### ⚠️ 关卡4：熔岩核心（策略卡点）

**预期体验**: 必须使用正确阵容，错误搭配必败

**敌人配置**:
- 1个泰坦石护卫（720HP，3个防御技能）
- 2个烈焰祭司（350HP，高爆发AOE）

**测试要点**:
- [ ] **测试1 - 错误阵容（3个脆皮输出）**: 应该被祭司AOE秒杀 ❌
- [ ] **测试2 - 错误阵容（3个坦克）**: 应该打不死祭司，被AOE磨死 ❌
- [ ] **测试3 - 正确阵容（1坦克+2输出）**: 应该能通关 ✅
- [ ] 泰坦的三层防御（护盾+减伤+高HP）是否生效
- [ ] 祭司的烈焰新星（70范围伤害）是否强力
- [ ] 祭司的火焰流星雨（25/秒，4秒）是否致命
- [ ] 5个熔岩点是否封锁了大部分战场

**测试战术**:
1. 坦克冲前排，吸引泰坦注意
2. 输出全力集火左边祭司
3. 击杀后集火右边祭司
4. 最后慢磨泰坦

**成功标准**: 
- 错误阵容必败
- 正确阵容能通关
- 玩家能理解"需要坦克+输出"的策略要求

---

### 👑 关卡5：火山领主的挑战（Boss战）

**预期体验**: 终极挑战，需要应对3个Boss技能

**Boss信息**:
- 火山领主·伊格尼斯
- HP: 1100
- 伤害: 50（狂暴后75）
- 3个技能

**测试要点**:
- [ ] **技能1 - 炼狱波动**: 90伤害+击退，9秒CD
- [ ] **技能2 - 熔岩柱**: 120伤害地面AOE，10秒CD
- [ ] **技能3 - 火山之怒**: +50%攻击+速度，8秒持续，20秒CD
- [ ] Boss没有陨石天降和召唤技能（已移除）
- [ ] 环境燃烧25点/秒（90秒累计2250）
- [ ] 4个熔岩点，十字形布局
- [ ] Boss狂暴后攻击提升到75，速度提升到48

**测试战术**:
- 分散站位，避免炼狱波动集体击退
- 看到地面标记，躲避熔岩柱
- Boss开启火山之怒时，风筝或开盾

**推荐阵容**:
- 1坦克 + 1治疗 + 1输出（持久战）
- 1坦克 + 2输出（速战速决）
