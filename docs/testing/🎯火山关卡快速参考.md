## 🎯 首次通关建议

### 最低配置
- **等级**: 3级+
- **人数**: 至少4个英雄
- **配置**: 1坦克 + 2输出 + 1治疗/辅助

### 关卡4+推荐
- **等级**: 5级+
- **人数**: 满编6人
- **配置**: 2坦克 + 3输出 + 1治疗
- **元素**: 至少2个水系或冰系

### Boss战推荐
- **等级**: 6级+
- **人数**: 满编6人，练度高
- **配置**: 2坦克 + 2输出 + 2治疗
- **元素**: 水+冰组合，克制火系

## ⚠️ 重要提示

1. **火系免疫燃烧**: 所有火系小怪不受环境伤害
