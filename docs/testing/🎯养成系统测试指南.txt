========================================
📋 完整测试流程
========================================

【第一步：准备工作】

1. 刷新页面 (Ctrl+F5)

2. 确保有角色
   - 如果没有，去"🎭 招募英雄"
   - 至少招募1个角色

3. 检查主页按钮
   ✅ 招募英雄（蓝色）
   ✅ 养成训练（粉色，暂时灰色禁用）
   ✅ 出发冒险（紫色）

========================================
【第二步：战斗获得俘虏】
========================================

1. 点击"⚔️ 出发冒险"

2. 布置阵型
   - 拖动角色到我方区域
   - 可以看到敌方阵容
   - 点击"开始战斗"

3. 战斗并获胜
   - 等待战斗完成
   - 击败所有敌人
   - Phaser 显示"胜利！"

4. 点击"选择俘虏"按钮
   ⚠️ 注意：这里按钮文字改了！
   胜利时：选择俘虏（橙色）
   失败时：返回主页（蓝色）

========================================
【第三步：俘虏选择】
========================================

1. 自动弹出俘虏选择Modal
   ✅ 金色边框
   ✅ 标题："🎉 胜利！选择一名敌人成为俘虏"
   ✅ 显示当前俘虏数量：0/10

2. 查看被击败的敌人
   ✅ 显示3个敌人卡片
   ✅ 每个敌人显示：
      - 职业图标
      - 名称
      - 属性（HP、攻击、类型）
      - 技能列表（名称+描述）

3. 选择一个敌人
   - 点击任意一个敌人卡片
   - 卡片变黄色高亮
   - 顶部显示"✓ 已选择"

4. 确认俘虏
   - 点击"确认俘虏"按钮
   - Modal关闭
   - 返回主页

========================================
【第四步：进入养成训练】
========================================

1. 主页变化检查
   ✅ "✨ 养成训练"按钮现在可用
   ✅ 按钮右上角显示橙色徽章"1"
   
2. 点击"✨ 养成训练"

3. 进入养成训练界面
   ✅ 标题："养成训练场"
   ✅ 副标题："选择角色和俘虏，让角色学习俘虏的技能"

========================================
【第五步：技能学习】
========================================

1. 左侧：选择要训练的角色
   - 点击一个角色卡片
   - 卡片变蓝色高亮
   - 顶部显示"✓ 已选择"
   - 查看角色信息：
     ✅ 当前技能列表
     ✅ 技能槽状态（x/3）

2. 右侧：选择俘虏作为材料
   - 点击一个俘虏卡片
   - 卡片变橙色高亮
   - 顶部显示"✓ 已选择"
   - 查看俘虏信息：
     ✅ 可学技能数量
     ✅ 技能详细信息

3. 点击"✨ 开始学习技能"按钮
   - 按钮文字变为"学习中..."
   - 等待1.5秒（学习动画）

4. 弹出学习结果Modal
   ✅ 标题："🎉 学习成功！"
   ✅ 绿色卡片：显示学会的新技能
      - 技能图标
      - 技能名称
      - 技能描述
   ✅ 红色卡片（如果技能槽满）：
      - 显示被替换的旧技能

5. 点击"继续训练"
   - Modal关闭
   - 俘虏消失（已被消耗）
   - 角色技能已更新

========================================
【第六步：验证结果】
========================================

1. 检查养成训练界面
   - 左侧角色技能已更新
   - 右侧俘虏数量减1
   - 俘虏列表：0/10

2. 返回主页
   - 点击"返回主页"按钮
   - 检查"养成训练"按钮：
     ✅ 徽章消失（俘虏数=0）
     ✅ 按钮禁用（灰色）

3. 查看角色列表
   - 点击"查看技能详情"
   - 确认新技能出现
   - 确认旧技能消失（如有替换）
