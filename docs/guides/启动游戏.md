# 🎮 火山关卡启动指南

## 🚀 方法一：一键修复和启动（推荐）

### 步骤：
1. 停止当前运行的服务器（如果有的话）：按 `Ctrl + C`
2. 在项目根目录运行：

```powershell
.\fix-and-start.ps1
```

**说明：** 这个脚本会自动清理所有缓存并启动服务器。

---

## 🧹 方法二：完全清理重装（如果方法一无效）

### 步骤：
1. 停止当前运行的服务器
2. 运行：

```powershell
.\quick-clean.ps1
```

3. 根据提示输入 `yes` 确认
4. 等待依赖重新安装（约2-3分钟）

**说明：** 这个脚本会删除 node_modules 并重新安装，解决所有缓存问题。

---

## 🔧 方法三：手动操作

如果脚本不工作，手动执行以下命令：

```powershell
# 进入项目目录
cd astrocade

# 清除缓存
Remove-Item -Recurse -Force .vite
Remove-Item -Recurse -Force node_modules\.vite
Remove-Item tsconfig.tsbuildinfo

# 启动服务器
npm run dev
```

---

## 🌐 打开游戏

服务器启动后，在浏览器中访问：

```
http://localhost:5173/
```

**重要：** 在浏览器中按 `Ctrl + Shift + R` 进行硬刷新（清除浏览器缓存）。

## 🐛 如果仍然有问题

### 检查错误信息：
1. 按 `F12` 打开浏览器开发者工具
2. 查看 Console 标签页
3. 截图或复制完整的错误信息

### 常见错误和解决方案：

#### 错误：`does not provide an export named 'ElementType'`
**解决方案：** 使用 `quick-clean.ps1` 完全重装

#### 错误：端口 5173 被占用
**解决方案：**
```powershell
# 查找占用端口的进程
netstat -ano | findstr :5173

# 结束进程（替换 <PID> 为实际进程ID）
taskkill /PID <PID> /F
```

#### 错误：npm 命令找不到
**解决方案：** 确保已安装 Node.js（推荐版本 18+）
