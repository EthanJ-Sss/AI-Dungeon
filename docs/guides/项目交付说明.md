## 🚀 如何使用

### 方法1：一键启动（最简单）⭐

1. **双击** `一键启动游戏.bat`
2. 首次使用选择 **`2`** 安装依赖
3. 之后选择 **`1`** 启动开发服务器
4. 浏览器自动打开游戏！

### 方法2：命令行启动

#### 使用CMD（推荐）
```cmd
# 进入项目目录
cd /d E:\circletest\astrocade

# 首次使用：安装依赖
npm install

# 启动开发服务器
npm run dev
```

#### 使用PowerShell（需要修改执行策略）
```powershell
# 以管理员身份打开PowerShell，运行：
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# 然后就可以正常使用npm命令
```

## 🎮 游戏测试流程

### 完整体验路径

1. **启动游戏**
   - 双击 `一键启动游戏.bat`
   - 选择 1 启动服务器
   - 浏览器打开 `http://localhost:5173`

2. **主页**
   - 查看游戏标题
   - 看到"暂无角色"提示

3. **招募英雄**
   - 点击"招募英雄"按钮
   - 查看"战士艾登"详细信息（HP、攻击、移速等）
   - 点击"确认招募"
   - 重复3次，招募3个角色

4. **阵型布置** ⭐ 重点测试
   - 点击"出发冒险"
   - 看到3列布局：
     - 左：我方3×3空网格（蓝色边框）
     - 中：可用角色列表
     - 右：敌方3×3网格（红色边框，3个敌人）
   - **拖拽测试：**
     - 拖动"战士艾登"到己方网格任意格子
     - 拖动"弓手艾莉"到其他格子
     - 拖动"刺客影"到第三个格子
     - 尝试重新拖动角色到不同位置
     - 点击已放置的角色移除它
   - **敌方预览：**
     - 确认敌方网格显示3个敌人
     - 位置在对角线：左上、中间、右下

5. **数据持久化**
   - 按F5刷新页面
   - 返回主页，角色列表仍然存在
   - 再次进入阵型布置，角色可用
