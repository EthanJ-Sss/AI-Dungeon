## 🐛 问题1：TailwindCSS PostCSS插件错误

### 错误信息
```
[plugin:vite:css] [postcss] It looks like you're trying to use `tailwindcss` 
directly as a PostCSS plugin. The PostCSS plugin has moved to a separate package...
```

### 问题原因
- 自动安装了TailwindCSS v4（最新版本）
- v4改变了PostCSS集成方式，需要单独的包
- 与当前配置不兼容

### 解决方案 ✅

#### 方案1：使用一键修复（推荐）⭐
1. 双击 `一键启动游戏.bat`
2. 选择 **`3`** - 修复依赖问题
3. 等待修复完成
4. 选择 **`1`** 启动服务器

#### 方案2：手动修复
```cmd
cd E:\circletest\astrocade
npm install
```

### 已修复内容
- ✅ 将TailwindCSS降级到稳定的v3.4.1
- ✅ 更新了package.json配置
- ✅ 添加了一键修复选项

### 验证修复
启动服务器后，如果看到：
```
  VITE v7.x.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
```
说明修复成功！

## 🐛 问题2：PowerShell禁止运行脚本

### 错误信息
```
无法加载文件 C:\Program Files\nodejs\npm.ps1，因为在此系统上禁止运行脚本
```

### 问题原因
- Windows PowerShell默认执行策略限制
- 阻止运行npm等脚本

### 解决方案 ✅

#### 方案1：使用.bat文件（推荐）⭐
**完全不需要修改PowerShell策略！**

1. 双击 `一键启动游戏.bat`
2. 选择对应功能
3. .bat文件会自动使用CMD运行

#### 方案2：使用CMD命令提示符
1. 按 `Win + R`
2. 输入 `cmd` 回车
3. 运行命令：
```cmd
cd /d E:\circletest\astrocade
npm run dev
```

#### 方案3：修改PowerShell执行策略（永久解决）
以**管理员身份**打开PowerShell：
```powershell
# 查看当前策略
Get-ExecutionPolicy

# 修改为RemoteSigned（推荐）
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# 确认修改
输入 Y 回车
```

## 🐛 问题3：端口5173被占用

### 错误信息
```
Port 5173 is in use
```

### 问题原因
- 之前的开发服务器还在运行
- 或其他程序占用了5173端口

### 解决方案 ✅

#### 方案1：关闭占用端口的进程
```cmd
# 查找占用5173端口的进程
netstat -ano | findstr :5173

# 记下最后一列的PID（进程ID）
# 然后关闭进程
taskkill /PID 进程ID /F
```

#### 方案2：修改端口号
编辑 `astrocade/vite.config.ts`：
```typescript
export default defineConfig({
  server: {
    port: 5174, // 改成其他端口
  },
})
```

## 🐛 问题4：页面空白/无法加载

### 可能原因
1. 开发服务器未启动
2. 浏览器缓存问题
3. JavaScript错误

### 解决方案 ✅

#### 检查清单
1. **确认服务器运行**
   - 终端应该显示 `Local: http://localhost:5173/`

2. **检查浏览器控制台**
   - 按 `F12` 打开开发者工具
   - 查看Console标签是否有错误
   - 查看Network标签是否有请求失败

3. **清除浏览器缓存**
   - 按 `Ctrl + Shift + Delete`
   - 选择"清除缓存"
   - 或使用无痕模式：`Ctrl + Shift + N`

4. **硬刷新页面**
   - 按 `Ctrl + F5`（强制刷新）

## 🐛 问题5：依赖安装失败/速度慢

### 错误信息
```
npm ERR! network timeout
npm ERR! network This is a problem related to network connectivity
```

### 问题原因
- 网络问题
- npm官方源在国外，速度慢
- 连接超时

### 解决方案 ✅

#### 方案1：使用淘宝镜像源
```cmd
# 设置淘宝镜像
npm config set registry https://registry.npmmirror.com

# 验证设置
npm config get registry

# 重新安装
npm install
```

#### 方案2：使用cnpm
```cmd
# 安装cnpm
npm install -g cnpm --registry=https://registry.npmmirror.com

# 使用cnpm安装依赖
cnpm install
```

#### 方案3：增加超时时间
```cmd
# 设置超时时间为10分钟
npm config set timeout 600000

# 重新安装
npm install
```

## 🐛 问题6：node_modules无法删除

### 错误信息
```
无法删除文件：访问被拒绝
目录不是空的
```

### 问题原因
- 某些文件被进程占用
- 通常是开发服务器还在运行

### 解决方案 ✅

#### 方案1：关闭所有相关进程
1. 关闭所有CMD/PowerShell窗口
2. 关闭VS Code（如果打开了项目）
3. 关闭浏览器
4. 再次尝试删除

#### 方案2：使用工具强制删除
1. 下载工具：Unlocker、LockHunter
2. 右键点击node_modules
3. 使用工具解锁并删除

#### 方案3：重启电脑
如果以上方法都不行，重启电脑可以释放所有文件锁

## 🐛 问题7：TypeScript类型错误

### 错误信息
```
Type 'xxx' is not assignable to type 'xxx'
```

### 问题原因
- TypeScript类型不匹配
- 依赖包的类型定义缺失

### 解决方案 ✅

#### 方案1：安装类型定义
```cmd
# 安装React类型
npm install -D @types/react @types/react-dom

# 安装Node类型
npm install -D @types/node
```

#### 方案2：临时忽略类型检查
在出错的行上方添加：
```typescript
// @ts-ignore
```

#### 方案3：更新类型定义
```cmd
npm update @types/react @types/react-dom
```

## 🐛 问题10：数据丢失/不保存

### 现象
- 刷新页面后角色列表消失
- LocalStorage数据丢失

### 解决方案 ✅

#### 检查清单
1. **检查LocalStorage是否可用**
   - 按 `F12` 打开开发者工具
   - Application标签 → LocalStorage
   - 查看是否有 `player-storage` 项

2. **浏览器隐私模式**
   - 无痕模式下LocalStorage可能被禁用
   - 使用普通模式打开

3. **浏览器设置**
   - 确保没有设置"关闭浏览器时清除数据"

4. **手动清除测试**
```javascript
// 在浏览器控制台运行
localStorage.clear()
// 然后刷新页面重新测试
```

## 📋 快速诊断清单

遇到问题时，按此顺序检查：

### 1. 环境检查

- [ ] node_modules存在
- [ ] package.json正确
- [ ] 依赖已安装

- [ ] 开发服务器正在运行
- [ ] 端口5173未被占用

- [ ] 使用Chrome/Edge/Firefox
- [ ] 版本较新

## 🆘 仍然无法解决？

### 完全重新开始

如果问题依然存在，尝试完全重新开始：

```cmd
# 1. 关闭所有相关进程和窗口

# 2. 删除node_modules和package-lock.json
# （如果无法删除，重启电脑）

# 3. 重新安装
cd E:\circletest\astrocade
npm install

# 4. 启动
npm run dev
```

### 检查系统环境

```cmd
# 检查Node.js版本
node --version
# 应该是 v18.x 或更高

# 检查npm版本
npm --version
# 应该是 9.x 或更高

# 检查npm配置
npm config list
```
