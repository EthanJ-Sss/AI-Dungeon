### 🐛 Bug修复

#### 1. 阵型布置拖拽Bug ✅
**问题：** 拖动第二个角色进入我方阵型时，第一个角色会消失

**原因：** 
```typescript
// 错误的数组初始化方式
Array(3).fill(null).map(() => Array(3).fill(null))
// fill()会导致所有行共享同一个数组引用
```

**修复：**
```typescript
// 正确的方式
Array.from({ length: 3 }, () => Array.from({ length: 3 }, () => null))
```

**文件：** `src/components/FormationPage.tsx`
- 修复玩家网格初始化
- 修复敌方网格初始化

## 📝 使用说明更新

### 新增操作说明

#### 战斗系统使用
1. 在阵型布置界面放置角色
2. 点击"开始战斗"
3. 进入战斗场景（Phaser）
4. 角色自动AI战斗
5. 观看战斗结果
6. 点击返回主页

#### 战斗操作
- 战斗全自动，无需操作
- 可以点击左上角"← 返回"重新布阵
- 观察血条判断战况
- 注意30秒计时器
