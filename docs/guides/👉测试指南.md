    - ❄️ 减速射击 = 冰蓝色
    - 😡 嘲讽吸引 = 红色

  - 角色放大1.1倍
  - 震动3次（yoyo效果）

- 📋 **控制台日志**：
  - 显示：`[技能释放] 技能名称`
