#### 普攻触发CD减少（-1秒）
**测试步骤**：
1. [ ] 观察角色普攻次数
2. [ ] 记录技能释放时间
3. [ ] 计算：`实际CD = 配置CD - 普攻次数`

- 预期：5秒后释放

**预期结果**：
- ✅ 每次普攻使CD-1秒
- ✅ 技能更快转好

**实际结果**：
- [ ] 通过 / [ ] 失败
- 观察：普攻___次，技能___秒释放

#### 受击触发CD减少（-0.5秒）
**测试步骤**：
1. [ ] 观察角色被攻击次数
2. [ ] 记录技能释放时间
