### 3. 关键方法检查

#### ✅ `initializeLavaBlocks()` - 初始化岩浆标记

```typescript
private initializeLavaBlocks() {
  this.lavaBlocks.forEach((block) => {
    // 岩浆标记位置（格子中心）
    const x = this.gridOffsetX + block.col * this.gridSize + this.gridSize / 2;
    const y = this.gridOffsetY + block.row * this.gridSize + this.gridSize / 2;

    // 创建岩浆地块标记（橙红色）
    const marker = this.add.rectangle(x, y, this.gridSize - 10, this.gridSize - 10, 0xff4500, 0.5);
    
    const key = `${block.row}-${block.col}`;
    this.lavaMarkers.set(key, marker);
  });
  
  console.log(`🌋 [岩浆系统] 初始化完成，共${this.lavaBlocks.length}个地块`);
}
```

**状态**: ✅ 正确实现
- 在每个岩浆地块位置创建橙红色标记
- 使用 Map 存储，方便后续查找

#### ✅ `startLavaEruptions()` - 启动喷发系统

```typescript
private startLavaEruptions() {
  this.lavaBlocks.forEach((block) => {
    // 每个地块独立计时，带有初始延迟
    this.time.addEvent({
      delay: block.offsetTime,
      callback: () => {
        // 启动周期性喷发
        this.time.addEvent({
          delay: this.lavaInterval,
          callback: () => this.scheduleLavaEruption(block.row, block.col),
          callbackScope: this,
          loop: true,
        });
        // 立即触发第一次
        this.scheduleLavaEruption(block.row, block.col);
      },
      callbackScope: this,
    });
  });
  
  console.log(`🌋 [岩浆系统] 已为${this.lavaBlocks.length}个地块设置喷发计时器`);
}
```

**状态**: ✅ 正确实现
- 每个地块独立计时
- 使用 offsetTime 错开喷发（避免同时喷发）
- 有控制台日志输出

#### ✅ `showLavaWarning()` - 警告特效

```typescript
private showLavaWarning(row: number, col: number) {
  const key = `${row}-${col}`;
  const marker = this.lavaMarkers.get(key);
  if (!marker) return;

  // 警告期间闪烁红色
  this.tweens.add({
    targets: marker,
    alpha: { from: 0.8, to: 0.3 },
    fillColor: { from: 0xff0000, to: 0xff4500 }, // 红色闪烁
    duration: 300,
    repeat: Math.floor(this.lavaWarningTime / 600) - 1,
    yoyo: true,
  });
}
```

**状态**: ✅ 正确实现
- 1.5秒闪烁警告
- 颜色从红色到橙红色来回变化
- 给玩家反应时间

#### ✅ `triggerLavaEruption()` - 触发喷发

```typescript
private triggerLavaEruption(row: number, col: number) {
  if (this.battleEnded) return;

  // 喷发特效位置（格子中心）
  const x = this.gridOffsetX + col * this.gridSize + this.gridSize / 2;
  const y = this.gridOffsetY + row * this.gridSize + this.gridSize / 2;

  // 喷发特效
  const eruption = this.add.text(x, y, '💥', {
    fontSize: '48px',
  }).setOrigin(0.5);

  console.log(`🌋 [岩浆喷发] 位置: (${row}, ${col})`);

  this.tweens.add({
    targets: eruption,
    scaleX: 1.5,
    scaleY: 1.5,
    alpha: 0,
    duration: 500,
    onComplete: () => eruption.destroy(),
  });

  // 对该地块上的所有单位造成伤害
  const allUnits = [...this.playerUnits, ...this.enemyUnits];
  allUnits.forEach((unit) => {
    if (!unit.isAlive) return;

    const container = this.allUnits.get(unit.character.id);
    if (!container) return;

    // 检查单位是否在岩浆地块上
    const unitGridX = Math.round((container.x - this.gridOffsetX) / this.gridSize);
    const unitGridY = Math.round((container.y - this.gridOffsetY) / this.gridSize);

    if (unitGridX === col && unitGridY === row) {
      console.log(`   ├─ 💥 ${unit.character.name} 被岩浆击中！`);
      // 计算岩浆伤害（考虑大地系抗性）
      const finalDamage = calculateLavaDamage(this.lavaDamage, unit.character.element);

      // 应用伤害
      unit.currentHp = Math.max(0, unit.currentHp - finalDamage);
      
      // 显示伤害数字
      // 更新HP条
      // 检查死亡
    }
  });
}
```

**状态**: ✅ 正确实现
- 显示喷发特效（💥）
- 检测地块上的所有单位
- 应用伤害（考虑元素抗性）
- 更新HP条和检查死亡

### 4. 元素系统集成 (`ElementManager.ts`)

#### 岩浆伤害计算

```typescript
export function calculateLavaDamage(baseDamage: number, element?: ElementType): number {
  const elementPassive = elementManager.getElementPassive(element);
  const multiplier = elementPassive?.lavaDamageMultiplier ?? 1.0;
  return Math.round(baseDamage * multiplier);
}
```

#### 元素抗性配置 (`elements.json`)

## 🔍 常见问题排查

### 问题1: 看不到岩浆标记

**可能原因**:
- ❌ 关卡配置中 `lavaBlocks` 为空
- ❌ 初始化时机错误
- ❌ 绘制层级被遮挡

**检查方法**:
```javascript
// 控制台查看关卡配置
console.log(currentLevel.lavaBlocks);

// 应该输出: [{ row: 2, col: 5 }] (关卡1)
```

**解决方案**:
- 确认 `levels.json` 中有 `lavaBlocks` 配置
- 检查 `initializeLavaBlocks()` 是否被调用

---

### 问题2: 岩浆不喷发

**可能原因**:
- ❌ `startLavaEruptions()` 未被调用
- ❌ 计时器未启动
- ❌ 战斗立即结束

**检查方法**:
```
查看控制台是否有:
🌋 [岩浆系统] 已为X个地块设置喷发计时器
```

**解决方案**:
- 确认 `create()` 中调用了 `this.startLavaEruptions()`
- 检查 `this.lavaBlocks` 数组不为空

---

### 问题3: 喷发但没有伤害

**可能原因**:
- ❌ 角色位置判定错误
- ❌ 伤害计算函数未导入
- ❌ HP更新未生效

**检查方法**:
```
查看控制台日志:
🌋 [岩浆喷发] 位置: (2, 5)
   ├─ 💥 圣骑士 被岩浆击中！  ← 如果没有这行，说明位置判定失败
```

**解决方案**:
- 检查 `unitGridX === col && unitGridY === row` 条件
- 确认 `calculateLavaDamage` 已导入
- 验证 `this.updateHealthBar(unit)` 被调用

---

### 问题4: 喷发频率过高/过低

**可能原因**:
- ❌ `lavaInterval` 设置不合理
- ❌ 多个计时器重复创建

**当前设置**:
```typescript
private lavaInterval = 10000;  // 10秒
```

**调整方法**:
```typescript
// 更快喷发
private lavaInterval = 5000;   // 5秒

// 更慢喷发
private lavaInterval = 15000;  // 15秒
```
