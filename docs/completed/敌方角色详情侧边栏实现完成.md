# 敌方角色详情侧边栏实现完成

**实现时间**: 2025-10-22  
**功能**: 在战场布阵界面点击敌方角色查看详细信息

---

## 功能概述

在布阵界面中，玩家现在可以点击敌方角色（列7-9区域）查看其详细属性和技能信息，帮助玩家制定更好的战术策略。

---

## 实现的功能

### 1. 可点击的敌方角色
- 敌方角色（列7-9区域）现在是可点击的
- 鼠标悬停时有缩放效果（scale-105）
- 添加了 `cursor-pointer` 样式提示可点击

### 2. 侧边栏展示
- 从屏幕右侧滑入的侧边栏（宽度384px）
- 平滑的滑入/滑出动画（300ms过渡）
- 半透明黑色遮罩层，点击可关闭
- 可滚动的内容区域

### 3. 角色详细信息

#### 基础属性
- **生命值**: 绿色高亮显示
- **攻击力**: 红色高亮显示
- **移动速度**: 蓝色高亮显示
- **攻击类型**: 近战/远程，黄色显示
- **职业**: 紫色显示（战士/射手/刺客/治疗）
- **元素**: 橙色显示，带元素图标（🔥❄️🪨💧⚪）

#### 主动技能列表
- 技能名称和冷却时间
- 技能描述
- 技能数值标签（伤害/治疗/范围）
- 如果角色没有主动技能，显示提示信息

## 技术实现

### 新增文件

**`astrocade/src/components/CharacterDetailSidebar.tsx`**
- 独立的侧边栏组件
- 使用固定定位 (`fixed`) 和变换 (`transform`) 实现滑动效果
- 从 `skills.json` 加载技能数据
- 响应式布局，垂直滚动支持

### 修改文件

**`astrocade/src/components/FormationPage.tsx`**

#### 1. 状态管理
```typescript
const [selectedEnemy, setSelectedEnemy] = useState<Character | null>(null);
const [showSidebar, setShowSidebar] = useState(false);

const handleEnemyClick = (character: Character) => {
  setSelectedEnemy(character);
  setShowSidebar(true);
};

const handleCloseSidebar = () => {
  setShowSidebar(false);
  setTimeout(() => setSelectedEnemy(null), 300);
};
```

#### 2. GridCell组件更新
- 新增 `onEnemyClick` 可选属性
- 添加 `handleCharacterClick` 处理函数
- 更新角色显示div的点击事件和样式

#### 3. 渲染侧边栏
```typescript
<CharacterDetailSidebar
  character={selectedEnemy}
  isOpen={showSidebar}
  onClose={handleCloseSidebar}
/>
```

## UI设计细节

### 配色方案
- **背景**: slate-900 (深灰色)
- **卡片**: slate-800/700 (中等灰色)
- **边框**: slate-700 (边框灰色)
- **文本**: white, slate-200-400 (渐变亮度)
- **属性颜色**: 
  - HP: green-400
  - 攻击: red-400
  - 速度: blue-400
  - 攻击类型: yellow-400
  - 职业: purple-400
  - 元素: orange-400

### 技能标签配色
- **伤害**: red-900/50背景 + red-200文字
- **治疗**: green-900/50背景 + green-200文字
- **范围**: purple-900/50背景 + purple-200文字
- **CD**: blue-600背景 + white文字

### 动画效果
- 侧边栏滑动: `transition-transform duration-300`
- 遮罩淡入淡出: `transition-opacity duration-300`
- 角色悬停: `hover:scale-105 transition-transform`
- 关闭按钮悬停: `hover:text-white`

## 用户交互流程

1. **打开详情**
   - 玩家在布阵界面点击敌方角色（列7-9）
   - 侧边栏从右侧滑入
   - 遮罩层淡入显示

2. **查看信息**
   - 查看角色的基础属性
   - 滚动查看所有主动技能
   - 了解技能的伤害/治疗数值

3. **关闭详情**
   - 点击关闭按钮（×）
   - 点击遮罩层外部
   - 侧边栏滑出，遮罩层淡出

4. **切换角色**
   - 点击其他敌方角色
   - 侧边栏内容立即更新为新角色信息

## 代码亮点

### 1. 延迟清除状态
```typescript
const handleCloseSidebar = () => {
  setShowSidebar(false);
  // 延迟清除，等待滑出动画完成
  setTimeout(() => setSelectedEnemy(null), 300);
};
```

### 2. 技能数据过滤
```typescript
useEffect(() => {
  if (character?.skills) {
    const characterSkills = (skillsData as SkillConfig[]).filter(skill =>
      character.skills?.includes(skill.id)
    );
    setSkills(characterSkills);
  }
}, [character]);
```

### 3. 条件渲染优化
```typescript
if (!character) return null; // 早期返回避免不必要的渲染
```

### 4. 动态样式
```typescript
className={`fixed right-0 top-0 h-full w-96 bg-slate-900 border-l-2 border-slate-700 
  shadow-2xl z-50 transform transition-transform duration-300 overflow-y-auto ${
  isOpen ? 'translate-x-0' : 'translate-x-full'
}`}
```
