## 🚀 使用方法

### 第一步：整理现有文件

```powershell
# 运行自动整理脚本
.\scripts\maintenance\整理项目目录.ps1
```

脚本会自动：
- 识别所有带Emoji的文档
- 移动到对应目录
- 显示移动进度
- 统计移动数量

### 第二步：遵守规范

**创建新文档时**:
1. 确定文档类型
2. 选择对应目录
3. 使用规范命名
4. 添加适当Emoji

**创建新脚本时**:
1. 确定脚本类型
2. 放入对应目录（deploy/dev/maintenance）
3. 使用描述性命名

### 第三步：定期检查

**每周检查**:
- [ ] 根目录是否有散落文档
- [ ] 新文档是否分类正确
- [ ] 脚本是否在正确目录

**每月整理**:
- [ ] 归档过时文档
- [ ] 清理重复文档
- [ ] 更新文档索引
