### 2. 随机招募系统 ✅

**特点**：
- 每次进入招募页面显示随机角色
- 优先显示未拥有的角色
- 如果所有角色都已拥有，则从全部角色池随机

**算法逻辑**：
```typescript
const getRandomCharacter = (): PresetCharacter => {
  // 筛选未拥有的角色
  const availableChars = charactersData.filter(
    char => !characters.some(c => c.name === char.name)
  );
  
  // 如果有未拥有的角色，从中随机
  if (availableChars.length > 0) {
    return availableChars[Math.floor(Math.random() * availableChars.length)];
  }
  
  // 否则从全部角色池随机
  return charactersData[Math.floor(Math.random() * charactersData.length)];
};
```

**useCallback 防止无限循环**：
