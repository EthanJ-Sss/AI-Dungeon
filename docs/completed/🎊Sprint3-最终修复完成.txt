🐛 修复的Bug清单
========================================

【Bug #1：缺失方法】
  错误：this.showDamageNumber is not a function
  
  原因：
    - 新技能调用了未实现的方法
    - showDamageNumber() 未定义
    - showDeathAnimation() 未定义
  
  修复：
    ✅ 添加 showDamageNumber() 方法
    ✅ 添加 showDeathAnimation() 方法
  
  影响：
    - 所有新技能现在能显示伤害数字
    - 所有单位死亡有流畅动画

【Bug #2：require 错误】
  错误：require is not defined
  
  原因：
    - 在 ES Modules 环境使用 CommonJS 语法
    - 3个技能内部使用了 require()
  
  修复：
    ✅ 删除 castFreeze 中的 require
    ✅ 删除 castSpeedBuff 中的 require
    ✅ 删除 castPoisonShot 中的 require
  
  影响：
    - 冰冻定身技能正常
    - 加速冲锋技能正常
    - 毒刺射击技能正常
