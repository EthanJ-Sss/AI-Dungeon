## 🐛 发现的问题

### 1️⃣ 敌方位置映射错误
- **问题**: 敌方位置映射使用的是旧的列号（8-10）
- **现象**: 敌方角色显示位置不正确
- **原因**: 列号从8-10改为7-9后，映射公式未更新

### 2️⃣ 岩浆可以出现在不可放置区域
- **问题**: 关卡4的岩浆配置包含 `row=0` 和 `row=4`
- **现象**: 岩浆会在边界行喷发
- **原因**: 岩浆配置没有遵循"行0和行4不可放置"的规则

### 3️⃣ 缺少防御性验证
- **问题**: 没有验证机制防止角色或岩浆被放置到行0和行4
- **现象**: 配置错误时不会报警，直接导致bug
- **原因**: 缺少验证代码

## 🛡️ 多层验证机制

### 第1层：配置文件验证
- **位置**: `levels.json`
- **规则**: 
  - 敌方 `position.y` 必须在 0-2
  - 岩浆 `lavaBlocks[].row` 必须在 1-3
  - 岩浆 `lavaBlocks[].col` 必须在 4-6

### 第2层：布阵界面验证
- **位置**: `FormationPage.tsx`
- **规则**:
  - 玩家拖放时检查 `isValidPlayerCell` (row 1-3, col 1-3)
  - 敌方加载时检查 `row >= 1 && row <= 3 && col >= 7 && col <= 9`
- **错误处理**: 
  - 不符合的角色不会加载
  - 输出 `console.error` 警告

### 第3层：战斗场景验证
- **位置**: `BattleScene.ts`
- **规则**:
  - 创建角色时检查 `globalRow >= 1 && globalRow <= 3`
- **错误处理**:
  - 输出详细错误信息（角色名、坐标、阵营）
  - 记录修正建议
  - 防止游戏崩溃
