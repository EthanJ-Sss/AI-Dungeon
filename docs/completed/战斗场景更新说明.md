### Bug #2：角色死亡后战斗卡住 ✅ 已修复
**问题描述**：第一个角色死后，战斗停止响应
**原因**：
1. 死亡角色容器被销毁但未从`allUnits` Map中移除
2. AI循环获取到无效容器导致错误
3. 缺少战斗结束标志，重复触发结束逻辑

**解决方案**：
1. 死亡时从`allUnits.delete()`移除容器引用
2. 所有容器获取处添加`active`有效性检查
3. 添加`battleEnded`标志防止重复执行
4. 在`create()`方法中完整重置所有状态
5. 在所有关键方法开始处检查`battleEnded`

**相关代码修改**：
```typescript
// 添加战斗结束标志
private battleEnded: boolean = false;

// 死亡时移除容器
if (target.currentHp <= 0 && target.isAlive) {
  target.isAlive = false;
  this.allUnits.delete(target.character.id);
  // ...
}

// AI更新时检查
private updateAI() {
  if (this.battleEnded) return;
  // ...
  if (!container || !container.active) return;
}

// 场景重置
create() {
  this.battleEnded = false;
  this.playerUnits = [];
  this.enemyUnits = [];
  this.allUnits.clear();
  // ...
}
```
