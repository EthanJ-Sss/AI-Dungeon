## 🐛 问题描述

**用户反馈**：
敌人现在是2个战士和1个弓手，但是全都在释放火球术。希望每个角色都能释放属于他的技能。

---

## 🔍 问题分析

### 原代码问题

**位置**：`src/game/scenes/BattleScene.ts` 第167-183行

**问题代码**：
```typescript
gameState.currentLevel.enemies.forEach((enemy, index) => {
  const enemyChar: Character = {
    id: `enemy_${enemy.characterId}_${Date.now()}`,
    name: `敌人${index + 1}`,
    hp: 150,
    maxHp: 150,
    damage: 15,
    moveSpeed: 2,
    attackType: 'melee',
    role: 'warrior',
    skills: ['skill_001'], // ❌ 所有敌人都硬编码为火球术
  };
  
  const unit = this.createBattleUnit(enemyChar, enemy.position, 'enemy');
  this.enemyUnits.push(unit);
});
```

**问题说明**：
- ❌ 所有敌人的属性都是硬编码
- ❌ 所有敌人的技能都是 `['skill_001']` (火球术)
- ❌ 完全忽略了 `enemy.characterId` 指向的角色配置
- ❌ 2个战士和1个弓手用了相同的技能

### 实际情况

根据 `levels.json`：
```json
"enemies": [
  { "characterId": 1 },  // 战士艾登
  { "characterId": 1 },  // 战士艾登
  { "characterId": 2 }   // 弓手艾莉
]
```

根据 `characters.json`：
```json
[
  {
    "id": 1,
    "name": "战士艾登",
    "role": "warrior",
    "skills": ["skill_005"]  // 嘲讽吸引
  },
  {
    "id": 2,
    "name": "弓手艾莉",
    "role": "archer",
    "skills": ["skill_004"]  // 减速射击
  }
]
```

**应该的效果**：
- ✅ 敌人1：战士，使用嘲讽吸引
- ✅ 敌人2：战士，使用嘲讽吸引
- ✅ 敌人3：弓手，使用减速射击

### 2. 从配置读取敌人数据 ✅

**修复前**：
```typescript
gameState.currentLevel.enemies.forEach((enemy, index) => {
  // ❌ 硬编码所有属性
  const enemyChar: Character = {
    id: `enemy_${enemy.characterId}_${Date.now()}`,
    name: `敌人${index + 1}`,
    hp: 150,
    maxHp: 150,
    damage: 15,
    moveSpeed: 2,
    attackType: 'melee',
    role: 'warrior',
    skills: ['skill_001'], // ❌ 所有敌人都用火球术
  };
  
  const unit = this.createBattleUnit(enemyChar, enemy.position, 'enemy');
  this.enemyUnits.push(unit);
});
```

**修复后**：
```typescript
gameState.currentLevel.enemies.forEach((enemy, index) => {
  // ✅ 从配置文件读取敌人角色数据
  const presetChar = charactersData.find(c => c.id === enemy.characterId) as PresetCharacter;
  
  if (!presetChar) {
    console.warn(`[BattleScene] 找不到角色配置 ID: ${enemy.characterId}`);
    return;
  }

  // ✅ 创建敌人角色（使用配置的所有属性）
  const enemyChar: Character = {
    id: `enemy_${enemy.characterId}_${Date.now()}_${index}`,
    name: `敌方-${presetChar.name}`,
    hp: presetChar.hp,          // ✅ 从配置读取
    maxHp: presetChar.hp,
    damage: presetChar.damage,  // ✅ 从配置读取
    moveSpeed: presetChar.moveSpeed,  // ✅ 从配置读取
    attackType: presetChar.attackType,  // ✅ 从配置读取
    role: presetChar.role,      // ✅ 从配置读取
    skills: presetChar.skills || [], // ✅ 从配置读取技能
  };
  
  console.log(`[BattleScene] 生成敌人: ${enemyChar.name}, 职业: ${enemyChar.role}, 技能: ${enemyChar.skills.join(', ')}`);
  
  const unit = this.createBattleUnit(enemyChar, enemy.position, 'enemy');
  this.enemyUnits.push(unit);
});
```
