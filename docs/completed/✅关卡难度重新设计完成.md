# ✅ 关卡难度重新设计完成

**更新日期**: 2025-10-22  
**版本**: 2.0 - 全新难度曲线  
**设计理念**: 从简单教学到策略挑战，循序渐进

---

## 🎯 设计目标

根据用户需求，重新规划5个关卡的难度设计：

1. ✅ **第一关**：极简教学关卡，让玩家轻松通关并学习技能
2. ✅ **第二、三关**：适度挑战，敌人技能和伤害递增
3. ✅ **第四关**：策略卡点关卡，需要特定阵型和角色组合
4. ✅ **第五关**：Boss战，从4个技能优化为3个强力技能

---

## 📋 关卡详细设计

### 🌋 关卡1：火山入口 - 新手教学关

**设计理念**: 让玩家轻松获胜，建立信心，学习技能系统

**敌人配置**:
- **幼年爬行者** x1
  - HP: 180（非常低）
  - 伤害: 18
  - 速度: 25
  - 技能: 弱爪击（20伤害，5秒CD）

**环境设置**:
- 环境燃烧: 3点/秒（最低）
- 熔岩喷发: 0个（无障碍）
- 时间限制: 50秒（充足）
- 难度标签: "新手"

**战术特点**:
- 只有1个弱小敌人
- 无熔岩障碍，战场宽敞
- 环境伤害极低
- 任何角色都能轻松获胜
- 完美的技能学习机会

**通关奖励**: 学习1次技能

### 🌋 关卡3：火山通道 - 进阶挑战

**设计理念**: 引入坦克+多技能组合，提升战斗复杂度

**敌人配置**:
- **熔岩巨兽** - 前排坦克（520HP，30伤害）
  - 技能: 熔岩之盾（120护盾）+ 岩浆跳跃（40伤害+眩晕）
- **火焰哨兵** - 中排射手（300HP，38伤害）
  - 技能: 烈焰箭（32伤害+点燃）
- **火山投石手·乙** - 后排（260HP，32伤害）
  - 技能: 投掷岩石（35伤害）
- **火山爬行者·丙** - 后排补充（280HP，26伤害）
  - 技能: 利爪突袭（28伤害）

**总计**: 4个敌人，总HP 1360

**环境设置**:
- 环境燃烧: 12点/秒
- 熔岩喷发: 2个 (1,4), (3,6)
- 时间限制: 65秒
- 难度标签: "中等"

**战术特点**:
- 巨兽护盾需要破盾战术
- 巨兽跳跃会眩晕，需要走位
- 火焰哨兵点燃效果持续伤害
- 4个敌人需要合理的集火顺序

**推荐集火顺序**: 哨兵 → 投石手 → 爬行者 → 巨兽

### 🌋 关卡4：熔岩核心 - ⚠️策略卡点⚠️

**设计理念**: 必须使用正确阵容和战术才能通关的策略关卡

**敌人配置**:
- **泰坦石护卫** - 超级坦克前排（720HP，32伤害）
  - 技能1: 泰坦之盾（200超级护盾，8秒）
  - 技能2: 地刺突起（50伤害+减速）
  - 技能3: 石肤术（减伤35%，6秒）
- **烈焰祭司·左** - 后排法师（350HP，50伤害）
  - 技能1: 烈焰新星（70范围AOE）
  - 技能2: 火焰流星雨（25/秒，持续4秒）
- **烈焰祭司·右** - 后排法师（350HP，50伤害）
  - 技能1: 烈焰新星（70范围AOE）
  - 技能2: 火焰流星雨（25/秒，持续4秒）

**总计**: 3个敌人，总HP 1420

**环境设置**:
- 环境燃烧: 18点/秒（高）
- 熔岩喷发: 5个（密集），封锁大部分战场
- 时间限制: 75秒
- 难度标签: "困难"

**策略要求** ⚠️:
1. **必须带坦克**: 泰坦会冲向前排，没有坦克扛伤害会被秒杀
2. **必须带输出**: 两个祭司AOE伤害爆炸，必须快速击杀
3. **集火顺序严格**: 必须先杀两个祭司，再慢磨泰坦
4. **走位要求高**: 5个熔岩点封锁战场，走位空间极小

**阵容推荐**:
- ✅ 1个高HP坦克（土系或冰系）+ 2个高爆发输出（水系/冰系克制火系）
- ❌ 3个脆皮输出：会被祭司AOE秒杀
- ❌ 3个坦克：打不死祭司，被AOE磨死
- ❌ 纯火系队伍：被克制

**战术细节**:
- 开局坦克直接冲前，吸引泰坦注意
- 输出全力集火左边祭司 → 右边祭司
- 祭司释放流星雨时立即走位
- 击杀两个祭司后，慢磨泰坦
- 注意泰坦三层防御机制（护盾+减伤+高HP）

### 🌋 关卡5：火山领主的挑战 - 👑Boss战👑

**设计理念**: 终极Boss，3个强力技能，考验综合实力

**敌人配置**:
- **火山领主·伊格尼斯** - 终极Boss（1100HP，50伤害）
  - 技能1: 炼狱波动（90伤害+击退，9秒CD）
  - 技能2: 熔岩柱（120伤害，地面AOE，10秒CD）
  - 技能3: 火山之怒（+50%攻击+50%速度，8秒持续，20秒CD）

**环境设置**:
- 环境燃烧: 25点/秒（极高）
- 熔岩喷发: 4个（十字形对称）
- 时间限制: 90秒
- 难度标签: "Boss"

**技能详解**:

1. **炼狱波动**（主要攻击技能）
   - 90伤害 + 击退效果
   - 范围AOE，需要分散站位
   - 9秒CD，频繁释放

2. **熔岩柱**（控制区域技能）
   - 120伤害，最高单体伤害
   - 地面AOE，会有预警标记
   - 10秒CD，需要预判走位

3. **火山之怒**（狂暴Buff）
   - 攻击提升50%（50→75伤害）
   - 速度提升50%（32→48速度）
   - 持续8秒，20秒CD
   - ⚠️ 开启后极度危险，需要风筝或开盾

**战术特点**:
- 1100HP，需要持久战
- 三个技能轮流释放，需要预判和应对
- 狂暴后伤害和速度暴增
- 环境伤害25/秒，90秒累计2250点
- 十字形熔岩配合Boss技能

**阵容推荐**:
- ✅ 1坦克 + 1治疗 + 1持续输出（水/冰系克制）
- ✅ 1坦克 + 2输出（速战速决）
- ❌ 纯输出无治疗：会被环境+技能伤害磨死

**战术细节**:
- 分散站位，避免炼狱波动集体击退
- 看到地面标记立即移动，躲避熔岩柱
- Boss开启火山之怒时：
  - 选项A：开盾硬扛
  - 选项B：风筝拉开距离
  - 选项C：使用控制技能
- 治疗持续回复环境燃烧伤害
- 利用熔岩位置卡Boss走位
