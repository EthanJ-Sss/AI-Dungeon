# 🔍 角色消失问题调试指南

## 🐛 问题描述

用户报告：**进入战斗后，会有一个角色直接消失**

从日志中观察到：
- `[BattleScene] 没有环境BUFF` - 环境BUFF系统未生效
- `💀 [角色死亡] 🛡️ 重装战士 已阵亡 (被未知击杀)` - 攻击者未知
- `💀 [角色死亡] 🛡️ 暗影刺客 已阵亡 (燃烧效果)` - 被燃烧杀死

---

### 3. 🔍 容器状态检查

**位置：** `generateBattleUnits` 方法末尾

**输出格式：**
```
🔍 [容器检查] 战斗开始0.5秒后，检查所有角色容器状态:
   🛡️ 炎魔战士: 存活=true, HP=225, 容器active=true, 可见=true, alpha=1

   🛡️ 大地守卫: 存活=true, HP=180, 容器active=true, 可见=true, alpha=1
   ⚔️ 敌方-火焰弓手: 存活=true, HP=150, 容器active=true, 可见=true, alpha=1
   ⚔️ 敌方-炎魔斗士: 存活=true, HP=165, 容器active=true, 可见=true, alpha=1
   ⚔️ 敌方-火焰术士: 存活=true, HP=120, 容器active=true, 可见=true, alpha=1
   总计: 6 个容器
```

**包含信息：**
- 角色名称和团队
- 存活状态（true/false）
- 当前HP
- 容器是否激活（active）
- 容器是否可见（visible）
- 透明度（alpha，正常=1）

**作用：** 诊断"角色消失"问题
- 如果 `容器active=false`：容器被意外销毁
- 如果 `可见=false`：容器被隐藏
- 如果 `alpha<1`：容器半透明或透明
- 如果 `存活=false` 但还在Map中：死亡处理异常

## 📊 可能的问题和诊断

### 问题1：角色立即死亡

**症状：**
```
✅ [角色创建] 🛡️ 暗影刺客 ...  HP:150

🔍 [容器检查] 战斗开始0.5秒后，检查所有角色容器状态:
   🛡️ 暗影刺客: 存活=false, HP=0, 容器active=false, 可见=false, alpha=0
```

**可能原因：**
1. 角色生成在岩浆上，立即被岩浆喷发击杀
2. 燃烧伤害过高，角色HP过低
3. 角色初始HP计算错误

**排查方法：**
1. 检查角色创建日志中的网格坐标
2. 对比岩浆地块位置（2,4）、（1,2）、（3,2）、（1,8）、（3,8）
3. 检查角色初始HP是否合理（应>100）
4. 检查死亡日志的死亡原因

---

### 问题2：角色直接消失（不死亡）

**症状：**
```
✅ [角色创建] 🛡️ 冰霜法师 ...  HP:150

🔍 [容器检查] 战斗开始0.5秒后，检查所有角色容器状态:
   🛡️ 冰霜法师: 存活=true, HP=150, 容器active=false, 可见=false, alpha=0
   总计: 5 个容器  (应该是6个！)
```

**可能原因：**
1. 容器被意外销毁（active=false）
2. 容器被隐藏（visible=false）
3. 容器透明（alpha=0）
4. 容器没有添加到场景

**排查方法：**
1. 检查 `createBattleUnit` 方法是否正常完成
2. 检查是否有其他代码修改了容器的visible或alpha
3. 检查是否有tween动画意外触发

---

### 问题3：被未知攻击者击杀

**症状：**
```
💀 [角色死亡] 🛡️ 重装战士 已阵亡 (被未知击杀) 当前HP:0.0 位置:(176, 186)
```

**原因：**
`dealDamage` 方法被调用时，`attacker` 参数为 `undefined`

**可能来源：**
1. 技能伤害没有传递攻击者
2. AOE技能没有正确设置攻击者
3. 环境伤害（燃烧/岩浆）误用了 `dealDamage`

**排查方法：**
1. 搜索所有调用 `dealDamage` 的位置
2. 检查是否都正确传递了 `attacker` 参数
3. 燃烧和岩浆应该使用 `handleUnitDeath(unit, "燃烧效果")` 而不是 `dealDamage`
