## 📂 新增文件

### `astrocade/src/utils/skillUtils.ts`

**功能**：技能工具函数库

**提供的函数**：

#### 1. `getSkillConfig(skillId: string)`
根据技能ID获取完整的技能配置

#### 2. `getSkillsInfo(skillIds: string[])`
根据技能ID列表获取技能信息（名称、描述）

**返回格式**：
```typescript
[
  {
    id: "skill_005",
    name: "嘲讽吸引",
    description: "嘲讽范围内所有敌人，强制其攻击自己，持续1秒"
  }
]
```

#### 3. `getSkillTypeIcon(skillId: string)`
根据技能ID或类型获取对应的图标

**图标映射**：
- 🔥 damage（伤害）
- 💚 heal（治疗）
- ⚡ teleport（传送）
- ❄️ debuff（减益）
- 😡 control（控制）

#### 4. `getSkillTypeColor(type: string)`
根据技能类型获取颜色类名（预留功能）

## 🧪 使用方法

### 在招募页面查看技能

5. **收起技能**：点击"收起技能详情 ▲"

## 💡 技术实现

### 工具函数设计

**skillUtils.ts** 提供了一套完整的技能信息处理工具：

```typescript
// 获取单个技能配置
const config = getSkillConfig('skill_005');
// => { id: 'skill_005', name: '嘲讽吸引', type: 'control', ... }

// 获取多个技能信息
const skills = getSkillsInfo(['skill_005', 'skill_004']);
// => [{ id, name, description }, ...]

// 获取技能图标
const icon = getSkillTypeIcon('skill_005');
// => '😡'
```

### 状态管理

使用 `useState` 管理展开/收起状态：

```typescript
const [expandedCharId, setExpandedCharId] = useState<string | null>(null);
```

- 只有一个角色的技能可以同时展开
- 点击其他角色会自动收起当前展开的角色

## 🔄 数据流程

### 招募页面

```
characters.json (角色配置)
    ↓
currentCharacter.skills (技能ID列表)
    ↓
getSkillsInfo(['skill_005'])
    ↓
skills.json (技能配置)
    ↓
[{ id, name, description }]
    ↓
渲染技能列表
```

### 主页

```
playerStore (角色数据)
    ↓
character.skills (技能ID列表)
    ↓
getSkillsInfo(character.skills)
    ↓
skills.json (技能配置)
    ↓
[{ id, name, description }]
    ↓
可展开的技能详情
```
