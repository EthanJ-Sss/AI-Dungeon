## 📐 详细配置

### 网格参数

```typescript
// BattleScene.ts
private gridSize = 56;          // 格子大小（像素）
private gridRows = 5;           // 5行
private gridCols = 11;          // 11列
private gridOffsetX = 120;      // 网格起始X坐标
private gridOffsetY = 130;      // 网格起始Y坐标

// 我方区域（蓝色）：列0-2，行1-3
private playerArea = { 
  rowStart: 1, rowEnd: 3, 
  colStart: 0, colEnd: 2 
};

// 敌方区域（红色）：列8-10，行1-3
private enemyArea = { 
  rowStart: 1, rowEnd: 3, 
  colStart: 8, colEnd: 10 
};
```

## 🐛 常见问题排查

### 问题1：角色位置不对应
**症状：** 布阵时放在某个位置，战斗中出现在其他位置

**排查：**
1. 检查 `createBattleUnit` 中的坐标映射逻辑
2. 确认 `playerArea` 和 `enemyArea` 配置正确
3. 验证 `gridOffsetX` 和 `gridOffsetY` 设置

**预期：** 
- 布阵列X → 战斗列X（玩家）
- 布阵列X → 战斗列(8+X)（敌人）
- 布阵行Y → 战斗行(1+Y)（都是）

---

### 问题2：岩浆喷发位置不正确
**症状：** 岩浆喷发动画不在标记的橙色矩形上

**排查：**
1. 检查 `scheduleLavaEruption` 中的坐标计算
2. 确认使用相同的 `gridOffsetX` 和 `gridSize`
3. 检查岩浆地块配置是否正确

**预期：**
- 警告标记和喷发动画应该在同一个格子中心

---

### 问题3：角色移动超出网格
**症状：** 角色移动时跑到网格外面

**排查：**
1. 检查角色移动逻辑是否有边界限制
2. 确认网格大小计算正确
3. 检查 `moveSpeedMultiplier` 是否过大

---

### 问题4：攻击距离不合理
**症状：** 近战角色离得很远就攻击，或远程角色必须贴脸

**排查：**
1. 检查攻击距离判定逻辑
2. 确认使用的是世界坐标而非格子坐标
3. 验证 `gridSize` 是否影响攻击距离计算
