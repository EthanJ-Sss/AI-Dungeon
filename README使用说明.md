# 🎮 AstroCade 游戏项目 - 使用说明

## ⚡ 最快启动方式

### 第一步：安装依赖（仅首次需要）
双击 **`一键启动游戏.bat`**，选择 **`2`** 安装依赖

### 第二步：启动游戏
双击 **`一键启动游戏.bat`**，选择 **`1`** 启动开发服务器

然后浏览器会自动打开游戏！

## 🐛 常见问题速查

### 问题1：PowerShell禁止运行脚本 ❌

**错误：** `无法加载文件...禁止运行脚本`

**解决：** 使用.bat文件（推荐）✅
- 直接双击 `一键启动游戏.bat`
- 或双击 `astrocade/启动开发服务器.bat`

详细解决方案见：`常见问题解决.md`

### 问题2：TailwindCSS PostCSS错误 ❌

**错误：** `[postcss] It looks like you're trying to use tailwindcss...`

**解决：** 使用一键修复 ✅
1. 双击 `一键启动游戏.bat`
2. 选择 **`3`** 修复依赖问题
3. 等待完成后选择 **`1`** 启动

**已修复：** TailwindCSS已降级到稳定的v3.4.1

### 问题3：端口被占用 ❌

**错误：** `Port 5173 is in use`

**解决：**
```cmd
# 查找进程
netstat -ano | findstr :5173
# 关闭进程（替换PID）
taskkill /PID 进程ID /F
```

### 问题4：页面空白 ❌

**解决：**
1. 按 `F12` 查看控制台错误
2. 按 `Ctrl + Shift + Delete` 清除缓存
3. 按 `Ctrl + F5` 硬刷新

## 🎯 测试游戏

1. 启动服务器后，浏览器打开 `http://localhost:5173`
2. 点击 **"招募英雄"** 招募3个角色
3. 点击 **"出发冒险"** 进入阵型布置
4. **拖拽角色**到己方3×3格子内
5. 查看敌方阵型预览
6. 点击 **"开始战斗"**（战斗系统开发中）

## 🆘 常见问题

### Q: 无法启动？
A: 确保已经安装依赖（选项2）

A: 按F12查看浏览器控制台错误

A: 使用.bat文件或CMD代替PowerShell
