# 在线系统集成说明

## 📦 新增文件

### 1. 核心服务层
- `src/services/supabase.ts` - Supabase 客户端配置
- `src/services/ladderApi.ts` - API 服务层（封装所有数据库操作）

### 2. 数据存储
- `src/store/ladderStoreOnline.ts` - 支持在线模式的新 Store

### 3. UI 组件
- `src/components/PlayerRegisterModal.tsx` - 玩家昵称注册界面

### 4. 配置文件
- `supabase-schema.sql` - 数据库表结构（在 Supabase 执行）
- `.env.local` - 环境变量（需手动创建）

---

## 🔧 如何使用

### 方式1：使用在线模式（推荐）

1. **配置 Supabase**
   ```bash
   # 创建 .env.local 文件
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=your-anon-key
   ```

2. **在 LadderPage.tsx 中使用新 Store**
   ```typescript
   // 修改导入
   import { useLadderStoreOnline } from '../store/ladderStoreOnline';
   
   // 在组件中使用
   const { 
     initializeLadder,
     registerPlayer,
     refreshLeaderboard,
     playerRegistered
   } = useLadderStoreOnline();
   
   // 显示注册界面
   {!playerRegistered && (
     <PlayerRegisterModal
       onRegisterSuccess={async (playerName, playerId) => {
         await registerPlayer(playerName);
         await initializeLadder();
       }}
     />
   )}
   ```

3. **启动开发服务器**
   ```bash
   npm run dev
   ```

---

### 方式2：保持本地模式

如果不配置 `.env.local`，系统会自动使用本地 mock 数据，无需任何改动。

## 🔄 从旧 Store 迁移

### 旧版本（本地模式）
```typescript
import { useLadderStore } from '../store/ladderStore';
```

### 新版本（支持在线）
```typescript
import { useLadderStoreOnline as useLadderStore } from '../store/ladderStoreOnline';

// API 几乎相同，但多了异步支持
await store.initializeLadder(); // 现在是异步的
```

## 🎮 完整使用示例

```typescript
// LadderPage.tsx 简化示例

import { useState, useEffect } from 'react';
import { useLadderStoreOnline } from '../store/ladderStoreOnline';
import PlayerRegisterModal from './PlayerRegisterModal';

export default function LadderPage() {
  const {
    leaderboard,
    myLadderData,
    isOnlineMode,
    playerRegistered,
    initializeLadder,
    registerPlayer,
    refreshLeaderboard,
  } = useLadderStoreOnline();
  
  const [showRegister, setShowRegister] = useState(false);
  
  useEffect(() => {
    // 初始化
    initializeLadder();
    
    // 检查是否需要显示注册界面
    if (!playerRegistered) {
      setShowRegister(true);
    }
  }, []);
  
  // 处理注册成功
  const handleRegisterSuccess = async (playerName: string) => {
    await registerPlayer(playerName);
    setShowRegister(false);
    await refreshLeaderboard();
  };
  
  return (
    <div>
      {/* 注册界面 */}
      {showRegister && (
        <PlayerRegisterModal
          onRegisterSuccess={handleRegisterSuccess}
          onSkip={() => setShowRegister(false)}
        />
      )}
      
      {/* 在线状态指示 */}
      <div>{isOnlineMode ? '🟢 在线模式' : '⚫ 本地模式'}</div>
      
      {/* 排行榜 */}
      <div>
        {leaderboard.map(player => (
          <div key={player.playerId}>
            #{player.currentRank} {player.playerName}
          </div>
        ))}
      </div>
    </div>
  );
}
```

## 🔑 关键变化

### 1. 异步操作
所有数据操作现在都是异步的：
```typescript
// 旧版本（同步）
store.initializeLadder();
store.executeChallenge(...);

// 新版本（异步）
await store.initializeLadder();
await store.executeChallenge(...);
```

### 2. 注册流程
新增玩家注册步骤：
```typescript
// 首次使用需要注册
if (!playerRegistered) {
  // 显示注册界面
  <PlayerRegisterModal ... />
}
```

### 3. 实时刷新
可以主动刷新排行榜：
```typescript
// 获取最新排名
await refreshLeaderboard();
```

## ⚠️ 注意事项

1. **保留旧 Store**
   - `ladderStore.ts` 保留，作为纯本地模式使用
   - `ladderStoreOnline.ts` 是新的在线版本

2. **渐进式升级**
   - 可以先不配置 Supabase，使用本地模式测试
   - 确认功能正常后再配置在线模式

3. **数据兼容性**
   - 两个 Store 的数据结构相同
   - 可以无缝切换

4. **错误处理**
   - 在线模式如果失败会自动fallback到本地模式
   - 不会影响游戏体验
