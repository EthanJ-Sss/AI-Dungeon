## ⚡ 超快速部署（只需2分钟）

### 第1步：创建 Supabase 项目（1分钟）

1. 打开 https://supabase.com
2. 点击右上角 **Sign In** → 使用 GitHub 登录
3. 点击 **New Project**
4. 填写：
   - 项目名称：`astrocade-ladder`
   - 密码：`Astrocade2025!`（记住这个）
   - 区域：`Northeast Asia (Tokyo)`
5. 点击 **Create new project**，等待1分钟

### 第2步：创建数据库（30秒）

1. 项目创建完成后，点击左侧 **SQL Editor**
2. 点击 **New query**
3. 打开项目文件 `astrocade/supabase-schema.sql`
4. 复制全部内容，粘贴到 SQL Editor
5. 点击右下角 **Run** 按钮
6. 看到 "Success" 提示

### 第3步：获取密钥（10秒）

1. 点击左侧 **Settings** → **API**
2. 复制两个值：
   - **Project URL**（类似：`https://xxxxx.supabase.co`）
   - **anon public key**（一长串字符）

### 第4步：配置和部署（20秒）

在项目目录运行：

```bash
# Windows
cd astrocade
一键部署在线系统.bat

# 按提示输入刚才复制的 URL 和 Key
```

**完成！** 🎉

## 🐛 如果遇到问题

### 问题1：显示"Supabase 未配置"
**解决**：检查 `.env.local` 文件是否存在，重新运行部署脚本

### 问题2：无法连接服务器
**解决**：
1. 检查 Supabase 项目是否正常运行
2. 检查 Project URL 是否正确

### 问题3：数据库错误
**解决**：重新在 SQL Editor 执行 `supabase-schema.sql`
