## 📊 技术说明

### 这个方案的优势

✅ **零外部依赖** - 不需要注册 Supabase、Firebase 等任何服务  
✅ **完全自主** - 数据保存在你自己的服务器  
✅ **极简架构** - 只需要 Node.js，无需数据库  
✅ **易于维护** - JSON 文件存储，随时查看和备份  
✅ **成本低廉** - 不产生任何外部服务费用  

### 数据存储位置

- 服务器: `/root/astrocade-server/data/`
  - `players.json` - 所有玩家数据
  - `challenges.json` - 挑战历史

可以直接查看和备份这些文件！

## 🔧 常见问题

### Q: 如何查看后端是否正常运行？

访问 `http://43.173.170.5:3001/api/health`，如果看到:
```json
{"status":"ok","message":"异步对战系统运行中"}
```
说明后端正常运行。

### Q: 如何备份数据？

在服务器上执行：
```bash
cd /root/astrocade-server
tar -czf backup-$(date +%Y%m%d).tar.gz data/
```

### Q: 前端如何知道后端地址？

通过环境变量配置，已自动创建：
- **开发环境**: 自动连接 `http://localhost:3001`
- **生产环境**: 连接 `http://43.173.170.5:3001`

如果连接失败，会自动降级到本地模拟模式。

### Q: 如何重启后端？

```bash
ssh root@43.173.170.5
pm2 restart ladder-api
```

### Q: 如何查看后端日志？

```bash
ssh root@43.173.170.5
pm2 logs ladder-api
```
