# 🚀 AstroCade 快速启动指南

## ⚡ 一键启动（推荐）

### 方式1：双击.bat文件（最简单）

1. **首次使用** - 双击 `安装依赖.bat`
   - 自动安装所有依赖包
   - 只需要运行一次

2. **启动开发服务器** - 双击 `启动开发服务器.bat`
   - 自动启动开发服务器
   - 浏览器访问: `http://localhost:5173`
   - 按 `Ctrl+C` 停止服务器

3. **构建生产版本** - 双击 `构建生产版本.bat`
   - 自动构建生产版本到 `dist/` 目录

### 方式2：使用命令行

如果您遇到 PowerShell 执行策略错误，请使用以下方法：

#### 方法A：使用CMD（命令提示符）
```cmd
# 进入项目目录
cd astrocade

# 安装依赖（首次使用）
npm install

# 启动开发服务器
npm run dev
```

#### 方法B：临时修改PowerShell执行策略
以**管理员身份**打开PowerShell，运行：
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

然后就可以正常使用npm命令了。

#### 方法C：使用完整路径
```powershell
# 使用node直接运行npm
node "C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js" run dev
```

## 📋 详细步骤

### 1️⃣ 检查环境

确保已安装 Node.js（版本 18+）：
```bash
node --version
```

### 2️⃣ 安装依赖

**首次使用必须执行：**

**方式A - 双击文件：**
- 双击 `安装依赖.bat`

**方式B - 命令行：**
```cmd
cd astrocade
npm install
```

预计安装时间：1-3分钟

### 3️⃣ 启动开发服务器

**方式A - 双击文件（推荐）：**
- 双击 `启动开发服务器.bat`
- 服务器启动后，打开浏览器访问 `http://localhost:5173`

**方式B - 命令行：**
```cmd
npm run dev
```

浏览器会自动打开游戏页面：

3. 拖拽角色到己方格子
4. 点击"开始战斗"（战斗系统开发中）

## 🐛 常见问题

### Q1: PowerShell报错"禁止运行脚本"

**问题：**
```
无法加载文件 C:\Program Files\nodejs\npm.ps1，因为在此系统上禁止运行脚本
```

**解决方案（3选1）：**

#### 方案1：使用.bat文件（推荐）✅
直接双击 `启动开发服务器.bat` 文件，不使用PowerShell

#### 方案2：修改执行策略
以**管理员身份**打开PowerShell：
```powershell
# 查看当前策略
Get-ExecutionPolicy

# 修改为RemoteSigned（推荐）
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# 或者修改为Unrestricted（不推荐）
Set-ExecutionPolicy -ExecutionPolicy Unrestricted -Scope CurrentUser
```

#### 方案3：使用CMD而不是PowerShell
1. 按 `Win+R`
2. 输入 `cmd` 回车
3. 使用命令行方式启动

### Q2: 端口5173被占用

**错误信息：**
```
Port 5173 is in use
```

**解决方案：**
1. 关闭占用端口的程序
2. 或者修改 `vite.config.ts` 中的端口号

### Q3: 依赖安装失败

**可能原因：**
- 网络问题
- npm镜像源速度慢

**解决方案：**
```cmd
# 使用淘宝镜像
npm config set registry https://registry.npmmirror.com

# 重新安装
npm install
```

### Q4: 页面空白/无法加载

**检查清单：**
1. 确保开发服务器正在运行
2. 检查浏览器控制台是否有错误
3. 尝试清除浏览器缓存（Ctrl+Shift+Delete）
4. 尝试使用无痕模式打开

## 🎮 游戏测试流程

### 完整测试步骤

1. **启动项目**
   - 双击 `启动开发服务器.bat`
   - 等待服务器启动
   - 浏览器自动打开 `http://localhost:5173`

2. **主页测试**
   - 检查页面是否正常显示
   - 应该看到"AstroCade"标题
   - 看到"招募英雄"和"出发冒险"按钮

3. **招募系统测试**
   - 点击"招募英雄"
   - 应该看到"战士艾登"的详细信息
   - 点击"确认招募"
   - 重复3次，招募3个角色
   - 自动返回主页

4. **阵型布置测试**
   - 点击"出发冒险"
   - 应该看到3列布局：
     - 左：我方3×3网格（空的）
     - 中：可用角色列表
     - 右：敌方3×3网格（有3个敌人）
   - **拖拽测试：**
     - 拖动"战士艾登"到己方格子
     - 拖动"弓手艾莉"到另一个格子
     - 拖动"刺客影"到第三个格子
     - 尝试重新拖动角色到其他格子
     - 点击已放置的角色尝试移除
   - **敌方预览测试：**
     - 检查敌方网格中是否有3个敌人
     - 位置应该在对角线：(0,0), (1,1), (2,2)
   - 点击"开始战斗"

5. **数据持久化测试**
   - 刷新页面（F5）
   - 角色列表应该还在
   - 再次进入阵型布置，角色仍然可用

## 💡 开发提示

### 热更新
- 修改代码后自动刷新浏览器
- 无需手动重启服务器

### 浏览器开发工具
- 按 `F12` 打开开发者工具
- Console标签：查看日志和错误
- Network标签：查看网络请求
- Application标签：查看LocalStorage数据

### 状态持久化
- 游戏数据自动保存到浏览器LocalStorage
- 清除数据：浏览器开发工具 → Application → LocalStorage → 删除
