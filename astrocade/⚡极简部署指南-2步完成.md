完全不依赖外部服务的在线异步对战系统！

## 🎯 部署方案

**在你现有的服务器上运行一个简单的 Node.js 后端**
- ✅ 无需注册任何外部服务
- ✅ 数据保存在你自己的服务器
- ✅ 使用 JSON 文件存储，无需数据库
- ✅ 完全可控，随时可以查看和备份数据

---

## 📦 第一步：在服务器上部署后端（5分钟）

### 1. 连接到你的服务器

```bash
ssh your_username@43.173.170.5
```

### 2. 上传后端代码到服务器

将 `astrocade/server/` 目录上传到服务器的某个位置，例如 `/home/yourusername/astrocade-server/`

你可以使用 `scp` 命令：

```bash
# 在你的本地电脑上运行
scp -r ./astrocade/server your_username@43.173.170.5:/home/yourusername/astrocade-server
```

或使用 SFTP 工具（如 FileZilla、WinSCP）上传。

### 3. 在服务器上安装依赖并启动后端

```bash
# 进入后端目录
cd /home/yourusername/astrocade-server

# 安装依赖
npm install

# 启动后端（推荐使用 pm2 保持运行）
npm install -g pm2
pm2 start index.js --name "ladder-api"
pm2 save
pm2 startup
```

**后端将运行在端口 3001**，确保防火墙允许访问此端口。

---

## 🎮 第二步：构建前端并部署（3分钟）

### 1. 配置前端 API 地址

创建 `astrocade/.env.production` 文件：

```env
VITE_API_URL=http://43.173.170.5:3001/api
```

### 2. 构建前端

```bash
cd astrocade
npm run build
```

### 3. 部署前端到服务器

将 `astrocade/dist/` 目录的内容上传到你服务器上的 Web 根目录（例如 `/var/www/html/` 或你当前的 8080 端口服务目录）。

```bash
# 在你的本地电脑上运行
scp -r ./astrocade/dist/* your_username@43.173.170.5:/var/www/html/
```

## 🔧 服务器配置参考（Nginx 反向代理）

如果你想让前端和后端使用同一个域名（避免跨域问题），可以配置 Nginx 反向代理：

```nginx
server {
    listen 8080;
    server_name 43.173.170.5;

    # 前端静态文件
    location / {
        root /var/www/html;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 代理
    location /api {
        proxy_pass http://localhost:3001/api;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

配置好后，前端 `.env.production` 只需要：

```env
VITE_API_URL=/api
```

这样前端和后端就在同一个域名下了。

## 📊 数据管理

### 查看数据

数据保存在服务器的 `astrocade-server/data/` 目录：
- `players.json` - 所有玩家数据
- `challenges.json` - 挑战历史记录

可以直接查看和备份这些 JSON 文件。

### 备份数据

```bash
cd /home/yourusername/astrocade-server
tar -czf backup-$(date +%Y%m%d).tar.gz data/
```

### 重置数据（测试用）

访问 `http://43.173.170.5:3001/api/reset` 可以清空所有数据。
